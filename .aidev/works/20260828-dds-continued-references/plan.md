# 計画: 継続行にまたがる参照

## 作業順序と依存関係

1. 走査を `joinContinuations` に変え、run の長さで分岐（依存: なし）
2. 単体テスト（継続の前後・`&`・様式・**回帰**）（依存: 1）
3. e2e（サンプルに継続を入れる）（依存: 1）
4. 実機で折り直した結果を確かめる（対照つき）（依存: 1）

## リスク / 留意点

- **前 work の回帰**（単独のキーワード行が畳まれる）を再発させない。テストで固定。
- 実機の確認では**対照を必ず置く**（`SFLCSRRRN` はサブファイル制御レコード限定）。

## テスト方針

- 単体: 継続の後ろ側 / 前側 / `&` / 様式 / **回帰**の 5 件。戻して落ちることを見る。
- e2e: サンプルの `ERASE` を `OVERLAY +` の継続の先に置き、様式の改名で追えることを見る。
- 実機: 折り直した結果と元のソースの両方を `CRTDSPF` に通す。
