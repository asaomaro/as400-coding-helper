# 決定記録

## D1: run の長さで**書き換え方を分ける**

- 背景: 前 work は「区間でまとめて置き換えると関係のない行まで畳まれる」ので
  物理行ごとに書き換える形にした。継続を追うにはまとめる必要がある。
- 決定: `joinContinuations` の run が**1 行なら物理行のまま**、
  **複数行なら結合テキストで探して折り直す**。
- 理由: 前 work の回帰の原因は「**論理単位**の区間」をまとめたことで、
  継続の run とは別物。単独のキーワード行は `joinContinuations` が別の run として
  返すので、`R MAIN` の次の行が吸い込まれることはない。
- 影響: 継続の run は折り方が変わりうる（3 行が 1 行になった実測がある）。
  名前の長さが変われば桁も変わるので避けられない。

## D2: 実機の確認で**対照ごと落ちた**（2 回目）

- 背景: 折り直した結果を実機に流したら通らなかった。
- 決定: 対照（元のソース）も落ちていたので、原因は折り直しではなく
  **`SFLCSRRRN` を素の様式に書いていた**こと（サブファイル制御レコード限定）。
  サブファイルを正しく組んだら両方通った。
- 理由: このバッチだけで**対照が誤読を止めたのは 3 回目**
  （`SFLEND` / `HLPRCD` / ここ）。probe に対照を置くのは例外ではなく既定にする。
- 影響: `verify/verify-continued-rename.mjs` に経緯を注記として残した。
