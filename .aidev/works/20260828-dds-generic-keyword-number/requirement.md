# 要件: 総称のキーワード（`CAnn` / `CFnn`）に番号を入れさせる

## 背景 / 課題

キーワードの候補（`＋`）から `CFnn` を選ぶと、ソースに **`CFNN()`** と書かれる。
原典の総称（`nn` は番号の場所）をそのまま大文字にしているため。

**実機は通さない**（IBM i 7.3 / `CRTDSPF` で確認）:

| 書いた形 | 実機 |
|---|---|
| `CF03` / `CF03()` / `CF03(03)` | 通る |
| **`CFNN`** / **`CFNN()`** | **通らない** |
| `CF00` / `CF25` | 通らない（原典の範囲は `CF01 - CF24`）|

候補はファイル・レベルと様式レベルの**両方**に出るので、どちらからでも踏める。

## 目的 / ゴール

総称の候補を選んだときに、**番号を入れる場所だと分かり、番号を入れて初めて
ソースに入る**状態。実機が通さない形が書き出されない。

## ユーザーストーリー

- US1: DSPF を書く人として、`CFnn` を選んだら番号を聞いてほしい。
  なぜなら `CFNN()` が書かれてもコンパイルするまで気付けず、
  気付いても「候補から選んだのに」となるから。（受け入れ: AC1, AC2）
- US2: 同じ人として、**何番まで使えるか**をその場で知りたい。
  なぜなら範囲は原典にあるが、覚えている人はいないから。（受け入れ: AC3）

## スコープ

### 対象
- 候補の名前に**番号の場所**（`nn`）が残っているときの扱い。
- 使える番号の範囲を**原典のデータから**取り出して見せる。

### 対象外
- 番号そのものの検査（`CF25` を弾く）。**候補は入力の助けであって検証ではない**
  ——生テキストからは何でも書ける、という既存の方針を変えない。
- 引数が任意のキーワードに `()` を付けている件。実機は `PRINT()` / `OVERLAY()` /
  `CLEAR()` / `CF03()` を**通す**ので、誤りではない。別項目として起票する。

## 完了条件 (受け入れ基準)

- [ ] AC1: 総称の候補（`CAnn` / `CFnn`）を選んで確定しても、**ソースには入らない**。
- [ ] AC2: 入力欄に番号の場所より前（`CF`）が残り、続きを打てる。
- [ ] AC3: 使える番号の範囲（`CF01 - CF24`）が出る。**範囲は原典のデータから取る**
      （書き写さない）。
- [ ] AC4: 番号を入れた形（`CF03`）は今までどおり書き出される。
- [ ] AC5: 総称でない候補（`DSPSIZ` など）の振る舞いは変わらない。

## 相互作用の受け入れ基準

- [ ] AC-I1 閉じない: 番号が要るとき、入力欄は**開いたまま**（閉じると打ち直しになる）。
- [ ] AC-I2 何が要るか分かる: 範囲を添えた案内が出る。
- [ ] AC-I3 取り消せる: `Esc` で閉じて `＋` に戻るのは今までどおり。
