# 計画: 総称のキーワードに番号を入れさせる

## 作業順序と依存関係

1. 実機で通る形・通らない形を確かめる（依存: なし）
2. `genericKeywordPrefix` / `genericKeywordRange`（依存: 1）
3. `＋` の確定に分岐を入れる（依存: 2）
4. 単体テスト（依存: 2）
5. e2e（依存: 3）

## リスク / 留意点

- **打たれた綴りで判定しない**。`cfnn` を素通しすると同じ形が書き出される。
- 範囲の取り出しは日英で区切りが違う。両方を単体で見る。

## テスト方針

- 実機: `CFNN` / `CFNN()` が通らず `CF03` / `CA24` が通ることを確かめる。
- 単体: 総称の見分け・範囲の取り出し（日英）・総称でないものが素通りすること。
- e2e: 総称を確定してもソースに入らず、入力欄に `CF` が残り、範囲が出る。
- 戻して落ちることを確かめる。
