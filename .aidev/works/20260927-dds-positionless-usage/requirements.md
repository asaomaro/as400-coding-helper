# 要件: 使用を H / P / M にしたら位置欄を空ける

## 背景 / 課題
2026-09-27 の実操作調査（`docs/research/20260927-dds-editor-exploration/findings.md` の D9）で、DDS ビジュアルエディタのプロパティで
フィールドの使用を `H`（潜在）に変えても位置（39-44 桁）が残り、実機が CPD7443 で作成しなかった。
原典は「潜在フィールド、プログラム - システム間フィールド、またはメッセージ・フィールドについては、位置を指定することはできません」
（`FIELD-DSPF-pos3944.html`）、帳票は `P` で「位置は無効です」（`FIELD-PRTF-prtuse.html`）。

## 目的 / ゴール
使用を位置の持てないもの（画面 H・P・M、帳票 P）に変えると位置が空き、そのまま実機で作成できる。

紐づく charter ゴール: DDS の桁支援（ビジュアルエディタ）

## スコープ
### 対象外
- 潜在フィールドを最初から位置なしで置く入口（置き方の UI の判断が要る。backlog に残す）。
- 既存ソースの「H に位置」を検証で指摘する件（D18。同じバッチの次の項目）。

## 完了条件 (受け入れ基準)
- [ ] AC1: 画面で使用を H・P・M にすると 39-44 桁が空く。2 次画面サイズの位置の上書き行（`*DS4 … 6  6`）も消える。O では残る（単体テスト）。
- [ ] AC2: 帳票で使用を P にすると位置が空く。O では残る（単体テスト）。
- [ ] AC3: その経路で作った画面が実機でコンパイルできる。位置を残した対照は CPD7443（H・P）/ CPD7436（M）になる。
