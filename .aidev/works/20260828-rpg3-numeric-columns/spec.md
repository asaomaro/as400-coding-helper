# 仕様: RPG III の数値欄

## 設計方針

### 1. **確かめた欄だけ**に `numericOnly` を付ける

C 仕様の `FIELDLEN(49-51)` / `DECPOS(52)`、I 仕様の `FIELDBEG(44-47)` /
`FIELDEND(48-51)` / `DECPOS(52)`。F / O / E / L 仕様は**確かめていないので触らない**。

`help` に**実機で確かめたこと**を書く。原典が無いので、根拠はそこにしか残せない。

### 2. 行末で欄が切れていても**判定する**

固定長のレコードは空白で埋められる。「行が短い」は「残りが空白」と同じで、
欄の最後の桁に値が来ていなければ左詰め。実機はその形を通さない。

### 3. サンプルを直す

`RPG3SAMP.rpg` の長さを右寄せにし、小数を置く。直した形が実機で通ることを
対照つきで確かめる。

## 受け入れ基準との対応

- AC1: `verify/probe-rpg3-numeric.mjs` / `probe-rpg3-io.mjs`。
- AC2: 定義に `numericOnly`。単体で固定。
- AC3: サンプル 9 件で指摘ゼロ。
- AC4: `verify/verify-rpg3-fix.mjs`（対照つき）。
