# 要件: RPG III の桁属性を実機で確定する

## 背景 / 課題

RPG III の定義には **`numericOnly` の欄が 1 つも無い**。そのため
`.rpg` / `.sqlrpg` には `line-length` しか届かず、桁ずれを検出できない。

RPG/400 Reference が入手できないため**原典照合ができない**。
実機のコンパイラに判定させる（`probe-rpg3-opcodes.sh` と同じ手法）。

## 目的 / ゴール

RPG III の数値欄が実機の規則どおりに定義され、`.rpg` に桁の検査が届く状態。

## ユーザーストーリー

- US1: RPG III を触る人として、桁ずれを保存時に知りたい。
  なぜなら RPG III は移行資産で、**書いた本人が周りに居ないことが多い**から。
  （受け入れ: AC1, AC2, AC3）

## スコープ

### 対象
- 実機で確かめられた数値欄に `numericOnly` を付ける。

### 対象外
- 実機で確かめていない欄（F / O / E / L 仕様）。**確かめた欄だけ**に付ける。

## 完了条件 (受け入れ基準)

- [ ] AC1: 実機に判定させ、数値欄と右寄せの要否を**確定**する。
- [ ] AC2: 確かめた欄に `numericOnly` を付け、`.rpg` に検査が届く。
- [ ] AC3: 検証済みサンプルで偽陽性 0 件。
- [ ] AC4: 真陽性が出たらサンプルを直し、**直した形が実機で通る**ことを確かめる。
