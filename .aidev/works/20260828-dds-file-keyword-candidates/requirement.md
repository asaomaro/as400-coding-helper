# 要件: ファイル・レベルのキーワードの候補（`＋`）を出す

## 背景 / 課題

`20260828-dds-file-keyword-edit` でファイル・レベルのキーワードを編集できるように
したが、`＋`（候補から足す）だけは出していない。理由は当時こう書いた:

> 候補はキーワードの**使用レベル**で絞っており、ファイル・レベルの一覧をまだ持っていない。

**この見立ては誤りだった。** `resources/completion/dds-keywords.json` の `level` には
`file` が入っており、DSPF 47 件 / PRTF 9 件がある。原典から生成済み。

いまはファイル・レベルだけ生テキストで書くしかなく、**同じ画面で操作が 2 通り**になっている。

## 目的 / ゴール

ファイル・レベルの行を選んでも、様式・項目と**同じ手順**でキーワードを足せる状態。

## ユーザーストーリー

- US1: DSPF を書く人として、`DSPSIZ` や `INDARA` を候補から選んで足したい。
  なぜなら綴りを覚えていなくても書けるのが `＋` の値打ちで、
  ファイル・レベルだけそれが無いと綴りを調べに行くことになるから。（受け入れ: AC1, AC2, AC3）

## スコープ

### 対象
- ファイル・レベルの行に `＋` を出す。候補は `file` レベルで絞る。

### 対象外
- `CAnn` / `CFnn` の扱い（選ぶと `CFNN()` と書かれる）。**様式レベルで既に同じ**なので
  この work で持ち込む問題ではない。別項目として起票する。

## 完了条件 (受け入れ基準)

- [ ] AC1: ファイル・レベルの行を選ぶと `＋ 追加` が出る。
- [ ] AC2: 候補はファイル・レベルのものに絞られている（`DSPSIZ` が出て `COLOR` が出ない）。
- [ ] AC3: 選んだ候補が**そのファイル・レベルの行に入る**（一覧を出すだけにしない）。
- [ ] AC4: レベルを判別できなかったキーワードは、どのレベルでも候補に出る。

## 相互作用の受け入れ基準

- [ ] AC-I1 開く / 閉じる: `＋` で入力欄が開き、`Esc` で閉じて `＋` にフォーカスが戻る
      （様式・項目と同じ。既存の実装をそのまま使う）。
- [ ] AC-I2 既存を妨げない: 様式・項目の `＋` の振る舞いは変わらない。
