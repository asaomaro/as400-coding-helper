# 決定記録

## D1: 絞りを core に出す（`keywordsForLevel`）

- 背景: 候補の絞りは `ui.ts` の `datalist` を組む途中にインラインで書かれていた。
- 決定: `src/core/dds/ddsKeywords.ts` へ出し、UI はそれを呼ぶ。
- 理由: **画面に出る規則を単体で確かめられる**ようにするため。
  「DSPSIZ はファイル・レベルに出て、フィールド・レベルには出ない」は
  この work の主張そのものなので、主張をテストで固定できる形にした。
- 影響: 判断は変えていない（未設定はどこでも出す、も含めて同じ）。

## D2: `CAnn` / `CFnn` はこの work で扱わない

- 背景: 候補から `CFnn` を選ぶと `CFNN()` と書かれる（原典の総称をそのまま書く）。
- 決定: 直さない。**backlog に起票する。**
- 理由: 様式レベルの候補にも同じ 2 件が入っており、**この work が持ち込む問題ではない**。
  直し方（`CF01` を推すのか / 番号を促すのか）は決めが要り、
  有効な番号の範囲は実機で確かめたい。混ぜると両方が薄くなる。
- 影響: ファイル・レベルの候補 47 件のうち 2 件が同じ状態のまま出る。
