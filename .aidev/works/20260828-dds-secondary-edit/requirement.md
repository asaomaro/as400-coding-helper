# 要件: 2 次画面サイズでの編集

## 背景 / 課題

`20260828-dds-alternate-position` で 2 次画面サイズの絵を出せるようにしたが、
**掴んでも動かせない**（`decisions.md` D3）。位置を決めているのは項目の行ではなく
**位置の上書き行**なので、いまの `move` を通すと項目自身の行（＝1 次の位置）を
黙って書き換えてしまう。そのため早期 return で塞いである。

2 次の位置を直すにはテキストエディタへ戻るしかなく、デザイナの中で完結しない。

## 目的 / ゴール

2 次画面サイズの絵の上で項目を掴んで動かすと、**その位置だけ**が変わる状態。
1 次の位置は動かない。上書き行が無ければ作られる。

## ユーザーストーリー

- US1: DSPF を書く人として、2 次画面サイズの配置をデザイナで直したい。
  なぜなら 2 つのサイズを行き来しながら桁を合わせるのに、片方だけテキストで
  数えるのは 1 次でやめたはずの作業だから。（受け入れ: AC1, AC2, AC3）
- US2: 同じ人として、実機が通さない形は**書けないようにしてほしい**。
  なぜなら上書き行の規則は原典に無く、通らないと分かるのはコンパイルの時だから。
  （受け入れ: AC4, AC5）

## スコープ

### 対象
- 2 次の絵での `move`（行・桁）。宛先は位置の上書き行。
- 上書き行が無いときの新規作成（挿入位置と条件名の決定を含む）。

### 対象外
- 2 次の絵での `resize` / `remove` / 属性・キーワードの編集。
  長さも属性も**サイズで変わらない**（上書き行は長さ欄を持てない＝実機で確認）。
- PRTF。`DSPSIZ` は表示装置のキーワードで、帳票に 2 次画面サイズは無い。

## 完了条件 (受け入れ基準)

- [ ] AC1: 2 次の絵で項目を掴んで動かすと、上書き行の位置欄だけが変わる。
      項目の行（1 次の位置）は変わらない。
- [ ] AC2: 上書き行が無い項目を動かすと、**項目の run の直後**に上書き行が作られる。
      条件名は `DSPSIZ` の 2 次に対応するもの（ユーザー定義名があればそれ、
      無ければ IBM 提供名）。
- [ ] AC3: 作った上書き行は**条件名と位置だけ**を持つ（長さ・名前・キーワードを書かない）。
- [ ] AC4: 2 次画面サイズが宣言されていないファイルでは拒否する。
- [ ] AC5: PRTF では拒否する。

## 相互作用の受け入れ基準

- [ ] AC-I1 掴める: 2 次の絵で項目を掴める（いまは早期 return で塞いでいる）。
- [ ] AC-I2 取り消し: 動かせない項目を掴んだときは、理由をステータスに出して
      位置を変えない（黙って何も起きない、にしない）。
- [ ] AC-I3 既存を妨げない: 1 次の絵での `move` の振る舞いは変わらない。
