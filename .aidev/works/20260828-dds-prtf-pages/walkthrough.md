# レビューガイド: 複数ページの帳票

## 変更概要 / 目的

後戻りするスキップで**改ページ**するようにし、ページを切り替えて見られるようにする。
併せて**位置（インチ）**を追うようにした——原典が「行番号ではなく位置に基づいて」と
規定しているため。

## 重要ポイント（特に見てほしい所）

- **規定は `LPI` の詳細ページにあった**（`decisions.md` D2）。前 batch では
  `SKIPB` のページだけを見て「原典に無い」と判断し、実機に印刷させようとして
  取れず、着手を見送っていた。**探す場所が違っただけ**だった。
- **原典の計算例をそのままテストにしてある**（7 / 6.875 / 7.5 インチ）。
  3 つの数が一致するので、位置の積み上げ・スキップ先・行送りが同時に裏づく。
- **モデルは全ページ分を持ち、絞るのは描くとき**（D3）。ページを替えるたびに
  ホストへ作り直しを頼むと往復のあいだ絵が消える。
- **行の高さはまだ変えていない**（D4）。位置は正しく持つが、キャンバスは
  「行 ＝ 一定の高さ」のまま。別項目に残した。

## 処理フロー

```mermaid
flowchart TD
  A[様式] --> B["LPI(n) を読む（無ければファイル・レベル）"]
  B --> C{SKIPB(n)}
  C -->|"目標 = n ÷ lpi"| D{目標 < 現在位置}
  D -->|はい| E["改ページ（page += 1）"]
  D -->|いいえ| F[同じページ]
  E --> G[位置 = 目標]
  F --> G
  G --> H["SPACEB / SPACEA は n ÷ lpi だけ進む"]
  H --> I[様式の終わりで LPI がファイル・レベルへ戻る]
```

## 主要な変更箇所

- `src/core/dds/prtfLayout.ts` `Cursor` / `skipTo` / `advance` — 位置と改ページ。
  注記に原典の引用を置いてある。
- `src/core/dds/prtfRenderModel.ts` `selectPrintPage` — CLI と UI が共有する絞り込み。
- `src/dds/webview/ui.ts` `renderDensity` — ページ送り（密度と同じ帯）。

## リスク / 確認してほしい点

- **静的な絵はソースの順序で歩く**。実際の印刷順はプログラムが決めるので、
  ページが増えるのは**ソースの並び自体が後戻りを起こすとき**だけ。
  実サンプル（`CUSTRPT.prtf`）は 1 ページのまま。
- LPI が混ざる帳票では、**行の間隔だけ**が実機と違う（位置とページは合う）。
