# 仕様: 表示切替（SO/SI・属性バイト・グリッド・他様式・ズーム）

## 概要

確定デザイン C1 のツールバーのうち、**表示に関する切替**を実装する。
表示は UI 内で完結する——**ホストとの契約（`protocol.ts`）は増やさない**。

core に足すのは 1 つだけ: **区切り（`RenderSegment`）に SO/SI の種別**。
`{` と `}` を出し分けるのに要るが、**UI に「これは全角か」を判断させない**ため core が持つ。

## 設計方針

### D1. SO/SI は「空けてある桁」に描く

`constantSegments` は既に SO/SI を **`{ text: "", cols: 1 }`** として区切りに入れている
（桁は消費済み）。表示を入れたら**その区切りに `{` / `}` を描くだけ**。

**項目の前後に足さない。** 足すと幅が変わり、**全部の桁がずれる**（表示の有無で位置が動く）。

区別のために種別を足す:

```ts
export interface RenderSegment {
  readonly text: string;
  readonly cols: number;
  /** SO / SI の桁。表示切替で `{` `}` を描くのに使う。 */
  readonly shift?: "so" | "si";
}
```

記号は**既存の SOSI 表示と同じ `{` `}`**（`dbcsShiftMarkers.ts:18`/`:25`）。
テキストエディタとデザイナで別の記号を出すと、同じソースが別物に見える。

### D2. ズームは「実測値 × 倍率」。実測と表示を分けて持つ

`measure()` が求めるのは**実測値**。CSS 変数に入れるのは**実測値 × 倍率**。

```
cellWidth (実測) ──┐
                   ├─→ --cell-w = 実測 × zoom  ─→ ルーラー・行番号・キャンバス・項目
zoom (UI の状態) ──┘                            └─→ geometry に渡す metrics
```

**同じ値をすべてが参照する**ので、桁位置は倍率に関係なく一致する（`research.md` F3・F4）。
分けないと **次の `measure()` で倍率が二重に掛かる**（F の リスク2）。

段階は C1 に合わせて **90 / 100 / 125%**、加えて 150%（属性バイトの 1 桁を確かめる用）。

### D3. ズームにキーボードショートカットを張らない

C1 の未解決 #5「ズームの二重適用」は、**自前がキーを取ることで起きる**。
**ボタンだけにすれば衝突しない**——ホストの `Ctrl+=` はホストのものとして通る。

> 桁の正確さが売りの画面で実寸が信用できなくなるのは最悪なので、
> **取り合わない**ほうを選ぶ。ホスト側でエディタごと拡大されたときは、
> 自前の倍率表示（%）と食い違うが、**自前の倍率は「実測値に対する倍率」**なので
> ルーラーと項目は常に一致する（キャンバス内の整合は保たれる）。

### D4. 表示状態は UI が持ち、ホストに送らない

切替（SO/SI・属性バイト・グリッド・他様式）とズームは `render()` の外の状態。
**再描画で戻らない**（AC7）。ホストへは送らない——表示は文書の内容ではないので、
`protocol.ts` に足すと**契約が表示の都合で膨らむ**。

> 永続化（再起動をまたぐ）は本 work では行わない。VSCode の `getState`/`setState` や
> 単独起動の `localStorage` に載せるのは後続。

### D5. アクティブ様式は選択から導く。新しい状態を持たない

「他様式を淡く」の基準は**選択中の項目が属する様式**（`RenderItem.recordName`）。
選択が無いときは**全部を同じ濃さ**で出す（淡くする基準が無いので、暗くしない）。

淡さは `opacity: 0.35`。**読めなくなると意味が無い**ので、消さずに沈める程度に留める。

### D6. 桁勘定はプロパティに出す

選択中の**定数**について、区切りから内訳を組み立てる:

```
SO 1 + 全角 4 × 2 + SI 1 = 10 桁
```

区切り（`segments`）を数えるだけで作れる——**文字を数え直さない**。
フィールドには出さない（プレースホルダなので内訳に意味が無い）。

### D7. 「スナップ」は作らない

C1 のツールバーにあるが、**いまのドラッグは常にセルに吸着**しており、
自由配置という相手が存在しない。**存在しない機能のボタンを置かない**
——押しても何も起きないボタンは、利用者に「壊れている」と読ませる。

必要になったら（例: 相対桁の扱いを入れるとき）改めて設計する。

## インターフェース / データ構造

```ts
/** UI が持つ表示状態。ホストへは送らない。 */
interface DisplayOptions {
  readonly showShifts: boolean;      // SO/SI の `{ }`
  readonly showAttributes: boolean;  // 属性バイトのマーカー
  readonly showGrid: boolean;        // 桁のグリッド
  readonly dimOthers: boolean;       // 他様式を淡く
  readonly zoom: number;             // 0.9 / 1.0 / 1.25 / 1.5
}
```

既定は **SO/SI 切 / 属性バイト入 / グリッド入 / 他様式の淡色 入 / 100%**。
属性バイトとグリッドは**現状の見た目を既定**にする（既存利用者の見え方を変えない）。
他様式の淡色は**入りを既定**にする——複数様式が重なった絵は、そもそも読めないため。

## 振る舞いの詳細

| 操作 | 結果 |
|---|---|
| 「SO/SI」を入れる | DBCS 定数の SO/SI の桁に `{` `}` が出る。**項目の位置と幅は変わらない** |
| 「属性バイト」を切る | 淡いマーカーが消える。桁は変わらない |
| 「グリッド」を切る | キャンバスの罫線が消える。ルーラーと行番号は残る |
| 「他様式」を入れる | 選択中の項目の様式**以外**が淡くなる。選択が無ければ全部そのまま |
| ズームを選ぶ | セル・ルーラー・行番号・項目・属性バイトが同じ倍率で変わる。**掴んだ項目は指した桁に入る** |
| 定数を選ぶ | プロパティに桁勘定（`SO 1 + 全角 4×2 + SI 1 = 10 桁`）が出る |

### エッジケース

- **半角だけの定数**: SO/SI が無いので内訳は `半角 5 = 5 桁`。
- **全角が途切れる定数**（`あZい`）: SO/SI が 2 組出る。内訳もその通りに並べる。
- **幅不明の項目**: 区切りが空なので `{` `}` は出ない。桁勘定も出さない。
- **選択が無いとき**の淡色表示: **淡くしない**（基準が無い）。
- **ズーム中の測定**: フォント読み込み後の再測定でも**倍率は保たれる**（実測値だけ更新）。

## 受け入れ基準との対応

| AC | 満たし方 |
|---|---|
| AC1 SO/SI の表示 | 区切りに `shift` を持たせ、**空けてある桁**に描く（D1）。幅は変えない |
| AC2 桁勘定 | 区切りを数えて内訳を作る（D6）。合計は `printWidth` と一致（テストで固定） |
| AC3 属性バイト / グリッド | クラスで出し分け。状態は UI が保持（D4） |
| AC4 他様式の淡色 | 選択から様式を導く（D5） |
| AC5 ズームで桁が一致 | 実測 × 倍率を**同じ CSS 変数**に入れる（D2・`research.md` F3） |
| AC6 キーを張らない | ボタンのみ（D3） |
| AC7 再描画で戻らない | 状態は `render()` の外（D4） |
| AC8 非後退 | 触る範囲を UI と区切りの型に限定。`npm test` / `verify` / lint |
| AC9 両ホスト | 表示は UI 内で完結するので、**両ホストで自動的に同じ**。e2e で確認 |
| AC-I1 状態が見える | 入っている切替は `armed` クラス（既存の配置モードと同じ流儀） |
| AC-I2 即時反映 | 切替はその場で `render()` |
| AC-I3 キーボード | `<button>` なので `Tab` と `Enter`/`Space` が既定で効く |
| AC-I4 選択が外れない | 切替は選択に触らない |
| AC-I5 ズームの安全性 | `geometry` に渡す `metrics` も倍率込み（D2・`research.md` F4） |
