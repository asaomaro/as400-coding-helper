# 要件: 帳票の強調（`HIGHLIGHT` / `UNDERLINE` / `COLOR`）を描く

## 背景 / 課題

帳票のプレビューは**見え方を一切描いていない**。画面（DSPF）は
`20260827-dds-5250-colors` で実機の見え方（色・反転表示・下線・明滅・非表示）を
描けるようにしたが、帳票には `DSPATR` が無く、切替ごと出していなかった。

しかも**画面の表を帳票に当てていた**——`toRenderItem` は種別に関わらず
`resolveAppearanceUnder`（画面用）を通しており、帳票の `COLOR(BRN)` は読めず、
帳票に無い `COLOR(WHT)` は読めてしまう状態だった。

実機で確かめたところ（IBM i 7.3 / `CRTPRTF`）、帳票の語彙は画面と別物:

| 形 | 実機 |
|---|---|
| `DSPATR(HI)` を帳票に | **通らない** |
| `COLOR(WHT)` | **通らない**（画面にはある） |
| `COLOR(BLK)` / `COLOR(BRN)` | 通る（帳票にしかない） |
| `UNDERLINE` / `COLOR` を様式に | **通らない**（項目レベルのみ） |
| `HIGHLIGHT` を様式に | 通る（**中の全項目に効く**） |

## 目的 / ゴール

帳票のプレビューでも、実機で印刷される見え方（太字・下線・カラー）が分かる状態。
**画面の語彙を持ち込まない。**

## ユーザーストーリー

- US1: 帳票を書く人として、どの項目が太字・下線・色つきで出るか絵で見たい。
  なぜなら `HIGHLIGHT` を**様式に書くと中の全項目に効く**（原典）ため、
  ソースを読むだけでは何が太字になるか分からないから。（受け入れ: AC1, AC2, AC3）
- US2: 同じ人として、**装置によって変わるものは断定しないでほしい**。
  なぜなら原典自身が「出力装置によって異なります」と書いており、
  決め打ちの色を見せられると実機と違う絵を信じることになるから。（受け入れ: AC4）

## スコープ

### 対象
- `HIGHLIGHT`（太字。様式にも項目にも）
- `UNDERLINE`（下線。項目レベルのみ）
- `COLOR`（カラー名 8 つ。項目レベルのみ）

### 対象外
- カラーの装置依存の 4 形式（`*RGB` / `*CMYK` / `*CIELAB` / `*HIGHLIGHT`）の
  **色を決めること**。原典が装置依存と書いているので、指定があることだけを示す。
- `FONT` / `CPI` の見え方への反映。文字の形は絵に載せない。

## 完了条件 (受け入れ基準)

- [ ] AC1: `HIGHLIGHT` が太字で描かれ、**様式に書くと中の全項目**に効く。
- [ ] AC2: `UNDERLINE` が下線で描かれる。
- [ ] AC3: `COLOR` のカラー名 8 つが色で描かれる。**名前は原典から生成**する。
- [ ] AC4: 装置依存の形は**色を決めず**、指定があることだけを示す。
- [ ] AC5: **画面の表を帳票に当てない**（帳票の項目に 5250 配色が付かない）。
- [ ] AC6: 画面ファイルの振る舞いは変わらない（回帰）。

## 相互作用の受け入れ基準

- [ ] AC-I1 切替: 「見え方」の切替が帳票でも出て、切ると強調が消える。
- [ ] AC-I2 何が効いているか分かる: 吹き出しに太字・下線・カラーが出る。
