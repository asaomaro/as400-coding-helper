# 要件: H 仕様書を書き戻す・読み込む

## 背景 / 課題
2026-09-27 の実操作調査（`docs/research/20260927-f4-prompter-exploration/findings.md` の P1）で、ILE RPG の H 仕様書のプロンプターは
確定しても何も書かず（通知も無い）、既存の `     H DFTACTGRP(*NO) ACTGRP(*NEW)` の行で開いても全欄が空だった。
H 仕様書の欄はキーワード形式で桁を持たず、桁で読み書きする経路（`extractByColumns` / `buildRpgLineText`）が素通りさせていた。

## 目的 / ゴール
H 仕様書をプロンプターで読み書きできる。定義に無いキーワードは消さない。

紐づく charter ゴール: 固定長フォーマットの入力補助（プロンプター）

## 完了条件 (受け入れ基準)
- [ ] AC1: 確定した値が `NAME(値)` のキーワードとして 7 桁目から書かれる（単体テスト）。
- [ ] AC2: 既存の行から値を読む。定義に無いキーワード（`NOMAIN` 等）は残し、空にしたものは外す。無変更の確定で元の行のまま（単体テスト）。
- [ ] AC3: 80 桁を超えたら H の行を足して続ける（単体テスト）。書いた H 仕様書が実機でコンパイルできる。
- [ ] AC4: 本物の VS Code で、H の行の F4 が既存の値を読み、確定すると書かれる。
