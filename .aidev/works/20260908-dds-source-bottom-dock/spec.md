# 仕様

## どこに置くか

**ドックは UI 本体（`src/dds/webview/`）に持つ。** 決定 #2 のとおり、
スタンドアロンと VSCode で同じものが出る形にする。
いま harness（`dev/standalone.html`）が持っている `#sourcePane` は**そちらから外す**。

## ソースの届け方

**`RenderModel` には入れない。** あれは *描くための* モデルで、生のソース行は描画データではない。
プロトコル層（`webview/protocol.ts`）のホスト → UI メッセージに足す。

```ts
| { type: "load";     model; host; source: readonly string[]; keywords? }
| { type: "applied";  model; source: readonly string[] }
| { type: "rejected"; model; source: readonly string[]; rejections }
```

**変更行の印は UI 側で出す。** `load` で受け取ったものを原本として持ち、
以降の `source` と突き合わせる。ホストに `changedLines` を送らせない
（差分の定義が 2 か所に散る）。

## 画面

```
┌ ツールバー ─────────────────────────────────────┐
├ ◧ 左 200px ─┬─ キャンバス ────────────┬─ 右 320px ◨ ┤
│  レコード様式 │                        │ プロパティ    │
├────────┴──── ⇕ グリップ ────┴────────┤
│ [ソース] [検証 ②]        ▤ 半分  ▣ 最大  ▾ 畳む      │
│  ソース or 検証（タブで切り替え）                      │
└──────────────────────────────────────┘
```

- **`.dds-diagnostics`（常設リスト）は無くす。** ドックのタブに入る。
- **タブ行は畳んでも残る。** 検証の件数バッジが常に見える（常設リストの代わり）。
- 左右ペインの見出しに畳むボタン（◧ / ◨）を置く。

## 振る舞い

| いつ | 何をするか |
|---|---|
| 開いたとき | 高さ **190px**（ソース 8 行）。前回の値があればそれ |
| 開いたとき | 診断にエラーがあれば **検証タブ**、無ければソースタブ |
| 開いたとき | 幅が足りなければ**左右ペインを畳む**（`needsWidth()` で判定） |
| 項目を選んだとき | ソース面をその行までスクロールし、強調する |
| 編集したとき | **タブを勝手に切り替えない**（見ているものを奪わない） |
| 畳む/広げる/幅を変えたとき | `localStorage` に残す |

**「開くときだけ判断し、以降は勝手に動かない」**で全部そろえる。

## 幅の判定

```
必要 = 桁数 × cellWidth + 行番号(3em) + 余白 + 枠
使える = ペイン幅 − (左が開いていれば 200) − (右が開いていれば 320)
```

`cellWidth` は**実測値**（`this.cellWidth`）を使う。決め打ちにすると字体が変わったとき静かにずれる。

## 保存

`localStorage` を直接使う（`ui.ts` 内）。**ホストに依らない**ので `Bridge` を増やさない。
読み書きは try/catch で囲む（使えない文脈がある）。キーは `dds.dock`。

## 非対象

- ドック内でのソース編集（表示専用）。行を押すと `openSource` でホストのエディタへ飛ぶ。
- 198 桁の収容（畳んでも足りない。ズームで扱う）。
