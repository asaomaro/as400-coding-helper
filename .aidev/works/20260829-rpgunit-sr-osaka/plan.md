# 計画: RPGUnit を SR-OSAKA に導入する

## 実装方針

**触る前に確かめ、対照を置き、片付ける。** 実機への書き込みを伴うので、
各段で結果を確認してから次へ進む。バージョン判定は `DSPSAVF`（バイト列で判断しない）。

## 作業順序と依存関係

1. 配布物の取得とハッシュ記録（依存: なし）
2. SAVF を IFS 経由で `ASAOLIB` に載せる（依存: 1）
3. `DSPSAVF` で `Release level` と中身を確認（依存: 2）**——ここで版を確定する**
4. `RSTLIB` で `RPGUNIT` を作る（依存: 3）
5. 固定長 ＋ `**free`（対照）を `CRTRPGMOD` に通す（依存: 4）
6. `RUCRTRPG` → `RUCALLTST`（依存: 5）
7. 出力形式の採取（依存: 6）
8. 片付け（依存: 7）

## リスク / 留意点

- **実機への書き込みを伴う。** 失敗しても `DLTLIB RPGUNIT` / `CLRLIB` で戻せる形にする。
- **ジョブを残さない。** `MSGW` で止まったら `ENDJOB`。作業後に活動ジョブを確認する。
- **スプールは消さない**（他の作業の証跡を巻き込む）。名前を報告する。
- **他人のジョブを落とさない。** ロックは `CLRLIB` で回避する。

## テスト方針

| 見るもの | 手段 |
|---|---|
| 導入できたか | `OBJECT_STATISTICS('RPGUNIT','*ALL')` の主要オブジェクト |
| 固定長が書けるか | `CRTRPGMOD` の `RNS9305`（**対照 `**free` と並べる**） |
| テストが作れるか | `RUCRTRPG` 後に `FIXTST2 *SRVPGM` が在ること |
| 実行できるか | `RUCALLTST` の集計行（`2 test cases, 2 assertions, 1 failure`） |
| 失敗が分かるか | わざと落とすテストを 1 本入れ、書式とソース位置が出ること |
| 後始末 | IFS・不要 SAVF の削除、活動ジョブが無いこと |
