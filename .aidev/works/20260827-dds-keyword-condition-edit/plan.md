# 計画: キーワード行の条件を編集する

## 作業順序と依存関係
1. 群に置き換え範囲を持たせる（依存: なし）
2. `setKeywordCondition` の検証と適用（依存: 1）
3. メッセージの型検査（依存: 2）
4. プロパティの「キーワード行」欄（依存: 3）
5. テストと e2e（依存: 4）

## リスク / 留意点
- 代表行を宛先にできてしまうと、項目の条件を壊す。**引き当てで弾く。**
- 継続行を置き換え範囲に含めるとキーワードが消える。
- 短い形の記法を 2 つ作らない（項目の条件と同じものを使う）。

## テスト方針
- 項目の行が動かないことを見る（OR で行が増えるときも）。
- 宛先が代表行なら断ることを見る。
- 書き換えた条件が**見え方に効く**ことまで見る（読む側と繋がっている担保）。
- 配線（`parseEdit`）をテストで固定する。
- e2e で実際に打って、キーワード行の桁だけが変わることを見る。
