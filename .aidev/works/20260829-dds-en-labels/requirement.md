# 要件: 英語版 DDS 定義から日本語を無くす

## 背景 / 課題

`resources/prompter/dds/en/DDS-*.json` に**日本語が 146 箇所**残っている。
英語で開いても欄の名前が日本語で出る。

| 出所 | 例 |
|---|---|
| 欄の説明（`parameters[].description`） | `順序番号（1-5 桁目）` |
| ファイル全体の説明・ヘルプ | `印刷装置ファイルの定位置項目（A 仕様書）` |
| 選択肢のブランクのラベル | `（ブランク）Field name` |

原因は 2 つ。**欄の名前が桁定義（`dds-field-labels.json`、日本語）から来ている**ことと、
生成器に日本語がじか書きされていること。

`generate-dds-columns.mjs` は `--lang=en` を受けるが、**英語では桁が取れない**
（14 欄中 4 欄、ラベルは日本語のまま）。英語原典は `(positions N through M)` と
**数字の前**に語を置くのに、正規表現は後ろ（`桁目`）を期待している。

**RPG 側には「英語版に日本語が混ざらない」検査がある**
（`verify-rpg-spec-definitions.mjs`）が、DDS には無い。

出所: `.aidev/backlog/prompter.md`（`20260829-dds-restricted-expand` の review should-2）。

## 目的 / ゴール

**英語で開いたときに、欄の名前も説明も英語で出ている状態。**
そして**次に日本語が混ざったら検査が落ちる**状態。

紐づく charter ゴール: 「プロンプター定義の拡充」。

## ユーザーストーリー

- US1: **英語で使う開発者**として、F4 の欄の名前が英語で出てほしい。
  なぜなら、いまは**桁の名前がすべて日本語**で、英語版の意味をなしていないから。
  （受け入れ: AC1, AC2）
- US2: **この定義を後から広げる開発者**として、日本語が混ざったら検査で落ちてほしい。
  なぜなら、混入は**目で見ないと気付けず**、RPG 側には既にその検査があるから。
  （受け入れ: AC4）

## スコープ

### 対象
- `generate-dds-columns.mjs` に**英語の桁・ラベル抽出**を足す。
- `generate-dds-prompter.mjs` を言語対応にする（ラベル・種別名・ファイル説明・ブランクの接頭辞・桁の書き方）。
- `verify-dds-prompter.mjs` に**英語版に日本語が無いこと**の検査を足す。

### 対象外
- **日本語版の桁抽出は触らない**。検証済みで、ルーラーも読む。作り直すと同じ罠を二度踏む。
- 欄ごとの `help`（既に英語原典から来ている）。
- DDS 以外（CL / RPG）。
