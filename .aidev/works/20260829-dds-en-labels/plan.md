# 計画: 英語版 DDS 定義から日本語を無くす

## 作業順序と依存関係

1. **T1** `generate-dds-columns.mjs` に英語のリンク抽出と補完ラベルの言語対応（依存: なし）
2. **T2** `dds-*.en.json` を生成し、**桁が日本語版と一致**することを確かめる（依存: T1）
3. **T3** `generate-dds-prompter.mjs` を言語対応にする（依存: T2）
4. **T4** `verify-dds-prompter.mjs` に日本語混入と桁一致の検査（依存: T3）
5. **T5** テスト・再生成・**日本語版に差分が出ないこと**（依存: T4）

## リスク / 留意点

| リスク | 対応 |
|---|---|
| **日本語版が動く** | ja の経路は触らない。再生成後に `git diff` で ja 側の差分ゼロを確認（AC5） |
| 英語の桁がずれる | 検査で日英一致を強制（T4）。ずれたら生成器を直す |
| ルーラーが en を読み始める | `ruler.ts` は `dds-field-labels.json`（ja）を読む。**今回は変えない**（表示言語の切替は別の話） |
| 補完ラベルの取りこぼし | 日本語版と同じ位置に同じ数だけ補う。欄の数が日英で違えば検査が落ちる |

## テスト方針

- **英語版に日本語が無いこと**を単体テストと `npm run verify` の両方で固定。
- **日本語を混ぜると落ちること**を確かめる（検査が空回りしていないこと）。
- **日本語版の出力に差分が出ないこと**（AC5）。
- 値集合・`restricted` の日英一致（既存の検査）。往復検証。e2e。
