# 要件: 様式・項目のキーワードに条件（標識）を付けられるようにする

## 背景 / 課題
2026-09-27 の実操作調査（`docs/research/20260927-dds-editor-exploration/findings.md` の D10・D8）で、DDS ビジュアルエディタでは
- 様式のキーワードに条件を付ける手段が無く、`31 SFLDSP` / `33 SFLCLR` が書けない＝**サブファイル画面が組めない**（実機 CPD7490）。
- 項目のキーワードも、既に別の行に分かれているものにしか条件の欄が出ず、`40 COLOR(RED)` が一から作れない。
条件は「キーワードだけの行」の 7-16 桁に書くので、1 行に並んだキーワードを分ける操作が要る。

## 目的 / ゴール
様式・項目のキーワードの 1 つに条件を付けると、そのキーワードが条件つきの自分の行へ分かれて書かれる。

紐づく charter ゴール: DDS の桁支援（ビジュアルエディタ）

## 完了条件 (受け入れ基準)
- [ ] AC1: 様式のキーワード（`SFLDSP`）・項目のキーワード（`COLOR(RED)`）を条件つきの行へ移せる。元の行の他のキーワード・他の行の条件は変わらない（単体テスト）。
- [ ] AC2: 条件を付けられないキーワード（`EDTCDE`）は移さない（単体テスト）。
- [ ] AC3: プロパティのチップの「条件」から入れられ、`SFLCLR` に条件を付けると CPD7490 の指摘が消える（GUI e2e）。
- [ ] AC4: この経路で組んだサブファイル制御の画面が実機で作成できる。
