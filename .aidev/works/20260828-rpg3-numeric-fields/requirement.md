# 要件: RPG III の残りの数値欄を実機で確定する

## 背景 / 課題

`20260828-rpg3-fspec-reclen` で F 仕様の `RECLEN` までは実機で確定した。残るのは
F 仕様の `BLOCKLEN` / `RECADDRLEN` / `KEYSTART`、O 仕様の `SPACEBEFORE` /
`SPACEAFTER` / `SKIPBEFORE` / `SKIPAFTER` / `ENDPOS`、E 仕様・L 仕様。

RPG III は **IBM の RPG/400 Reference が入手できず原典照合ができない**。
PJ の規約どおり**実機のコンパイラに判定させる**しかない。

## 目的 / ゴール

RPG III の定位置の数値欄について、**どれが数字だけ・右寄せで、どれがそうでないかが
実機の根拠つきで決まっている状態**。lint が実機の通す形を弾かず、実機が通さない形を
見逃さない。

紐づく charter ゴール: 固定長ソースの桁を、原典・実機の根拠つきで支援する。

## 完了条件 (受け入れ基準)

- [ ] AC1: 対象の欄それぞれについて、**対照（通る形）つき**で実機の判定が取れている。
- [ ] AC2: 数字だけの欄に `numericOnly` が付き、lint が英字と左詰めを指摘する。
- [ ] AC3: **数字だけではない欄に `numericOnly` を付けていない**（実機が通す値を弾かない）。
- [ ] AC4: 付けた／付けなかった判断が、実機のメッセージ ID つきで `help` に残っている。
- [ ] AC5: 足した規則が**到達可能**である（定義を置いただけで終わっていない）。
- [ ] AC6: `docs/src` のサンプルに指摘が出ない（CI の桁位置 lint が緑）。
