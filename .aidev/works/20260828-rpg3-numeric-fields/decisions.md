# 決定記録

## D1: 空白必須の桁でも入力欄は残す（help で警告する）

- 背景: 実機が空白を要求する桁（F 20-23 / 47-52、L 25-74）に定義が入力欄を持っていた。
- 決定: 欄は消さず、`help` に「IBM i では空白でなければならない」とメッセージ ID を書き、
  既定では隠す（`visibleByDefault: false`）。
- 理由 / 代替案: 消すと**既存ソースを読み込んだときにその桁が画面に出ず、書き戻しで
  黙って消える**。PJ が `CHGPRTF` の単一値と `SNDPGMMSG` の `dependsOn` で二度踏んだ形。
  古いソースを読む用途がある以上、読めることを優先する。
- 影響: プロンプターに「書いてはいけない欄」が残る。help でしか止められない。
  実機が弾くこと自体は変わらないので、害は「気付くのが遅れる」に留まる。

## D2: `LABELS`(53 桁) を `CONTINUATION` に改名した

- 背景: 実機は 53 桁目を継続欄（`K` か空白）と言う（`QRG2067`）。定義は「ラベル」で、
  `S`/`E` を選ばせていた。既存の help は「MVT/MVS では空白」と書いており、
  **System/3x・MVS 系の資料から起こしたまま IBM i で確かめていなかった**と分かる。
- 決定: 名前・説明・help を実機に合わせる。
- 理由: RPG III は原典が無く、**実機が唯一の真実源**。否定（`E` が落ちる）だけでなく、
  継続行が通ることも確かめてから変えた。
- 影響: 定義の外から `LABELS` を参照している箇所は無い（確認済み）。
  54-59（選択）・60-65（記入）の欄はまだ無い——backlog に起票した。

## D3: サンプルを「通る形」にはしない（桁だけ直す）

- 背景: 桁を直しても `RPG3SAMP.rpg` はコンパイルが通らない。残るのは
  `QRG4118`（外部記述の I 仕様はレコード様式名を書く）と
  `QRG7023`（`IF` ＋ `SETON LR` なしで終了できない）。
- 決定: **桁だけ直す**。backlog 項目が求めているのは桁ずれの是正で、そこは実機で
  裏が取れた（リストが `CUSTMAS`/`CUSTREC` を解決し、全フィールドが対応づいた）。
- 理由 / 代替案: 終了手段を足すのは「この例で何を見せるか」の判断であって桁の話ではない。
  レコード様式名への差し替えも試したが、**対照（`CUSTREC` ＋ `NS` ＋ 標識）が落ちた**ので
  通る形が分かっていない。分からないまま直さない。
- 影響: サンプルは桁としては正しいが、まだコンパイルは通らない。
  理由はメッセージ ID つきで backlog に残した。
