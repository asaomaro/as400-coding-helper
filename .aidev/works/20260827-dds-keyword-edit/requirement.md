# 要件: キーワード欄を編集できるようにする（L3）

## 背景 / 課題

DSPF の実質的な記述は **45-80 桁のキーワード欄**に集中する。
`DSPATR(RI)` / `COLOR(RED)` / `EDTCDE(1)` / `CHECK(RZ)` — 見た目と入力規則のほとんどがここにある。

デザイナは**読めるようになった**（チップに分け、原典の解説を出す。`20260826-dds-keyword-help`）が、
**書けない**。キーワードを 1 つ足す・消す・引数を変えるだけのために、
テキストエディタへ戻って 45 桁目を数えることになる。

書き出しには**折り返し**が要る。キーワード欄は 36 桁（45-80）しかなく、
`DSPATR(RI HI)` を 2 つ足しただけで溢れる。折り返しの規則は
実機で確定済み（`20260827-dds-keyword-continuation`）。

紐づく charter ゴール: **DDS（DSPF/PRTF）の視覚的な確認と編集**を第 4 の柱として加える。

## 目的 / ゴール

**キーワードの追加・削除・引数の変更が、デザイナの中で完結している状態**。
書き出した結果を読み直すと**同じキーワードの並びに戻る**（桁が溢れても）。

## ユーザーストーリー

- US1: DSPF を直す開発者として、**キーワードを 1 つ消したい**。
  なぜなら、いまは 45 桁目を数えてテキストエディタで消すしかないから。（受け入れ: AC2, AC5）
- US2: DSPF を直す開発者として、**キーワードを足したい**。
  なぜなら、綴りを覚えていないと書けず、いまは補完のあるテキストエディタへ戻る必要があるから。
  （受け入れ: AC3, AC6）
- US3: DSPF を直す開発者として、**桁が溢れても壊れないでほしい**。
  なぜなら、36 桁は `DSPATR` と `COLOR` を並べただけで溢れ、
  **手で折ると継続記号を間違える**から。（受け入れ: AC1, AC4）

## スコープ

### 対象
- キーワード欄の**書き出し**（折り返しを含む）。
- 追加・削除・引数の変更。
- 継続にまたがる定数のリテラルの変更（前の work で拒否していたもの）。

### 対象外
- **引数の中身の検証**（`DSPATR(RI)` の `RI` が妥当か）。原典の構文は散文混じりで
  機械的な検証に耐えない。**名前の存在も検証しない**（チップの印で示すに留める）。
- **使用レベルの検証**（そのキーワードがその位置で書けるか）。
  レベルの解決を誤ると**正しい記述を拒否する**。
- ファイル・レベルのキーワード（一覧に出ていないので編集対象にならない）。
- 名前変更の参照追随。

## 機能要件

- 36 桁に収まらないときは**次の行へ折る**。
  - **キーワードの切れ目で折れるなら、切れ目で折る**（`-` を使わない）。
  - **1 つのキーワードが 36 桁に収まらないときだけ `-` で切る**。
- 折り返した結果を読み直すと、**元のキーワードの並びに戻る**。
- 定数のリテラルは**先頭に残る**（消えると項目でなくなる）。
- 条件付けの行・位置の桁は**触らない**。

## 非機能要件 / 制約

- **既存挙動を壊さない**: 位置・長さ・型・用途の編集は従来どおり。
- 折り返しの規則は**実機で確定したもの**を使う（`-` は空白を挟まず 45 桁目ちょうどから）。
- core は `vscode` を import しない。

## 完了条件 (受け入れ基準)

- [ ] AC1: 36 桁に収まらないキーワードの並びが、**切れ目で次の行へ折られる**。
- [ ] AC2: チップの `✕` でキーワードが 1 つ消え、ソースがそのとおりになる。
- [ ] AC3: 原典の一覧から選んでキーワードを足せる。
- [ ] AC4: **書き出し → 読み直しで、キーワードの並びが一致する**（折れても・`-` で切れても）。
- [ ] AC5: 定数のリテラルは先頭に残る。**リテラルを消す編集は拒否**され、理由が出る。
- [ ] AC6: 引数を直接書き換えられる（生テキストの編集）。
- [ ] AC7: 継続にまたがる定数のリテラルが**変更できる**（前の work の拒否が解ける）。
- [ ] AC8: 実機で、書き出した結果がコンパイルを通り、**解決後の値が編集前と同じ**になる
      （引数を変えていない場合）。

## 相互作用の受け入れ基準（UI を伴う work のみ）

- [ ] AC-I1 開く / 閉じる: `＋` で入力欄が開き、`Esc` で閉じる。
- [ ] AC-I2 確定 / 取り消し: 生テキストは `Enter` / フォーカスを外して確定、`Esc` で元に戻す。
- [ ] AC-I3 キーボードだけで完結するか: `Tab` でチップ → `✕` → `＋` → 入力欄に到達できる。
- [ ] AC-I4 フォーカスの行き先: 確定後は**同じ場所**に戻る（拒否されたら入力欄に留まる）。
- [ ] AC-I5 既存の操作を妨げないか: 入力中のキーを**キャンバスへ漏らさない**。
