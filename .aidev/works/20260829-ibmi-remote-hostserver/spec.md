# 仕様: `ibmi-remote` skill に hostserver 経路を足す

## 設計方針

**既存の節を消さない。** ssh 経路は pub400（共用機・ssh しか無い）で今も有効。
hostserver 経路は SR-OSAKA（自機・ホストサーバーが開いている）で使う。
**冒頭に「どちらを使うか」の分岐**を置き、末尾に hostserver の節を足す。

**落とし穴は「実際に踏んだ例」つきで書く。** 一般論として書くと読み飛ばされる。

## 対象範囲

`.claude/skills/ibmi-remote/SKILL.md` のみ。**コードは触らない。**
