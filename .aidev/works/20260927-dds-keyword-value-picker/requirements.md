# 要件: キーワードの値をドロップダウン／チェックボックスで選ぶ

## 背景 / 課題
`COLOR(RED)` や `DSPATR(HI)` のように括弧の中に値を書くキーワードは、値を手で打つしかなかった（キーワードを足すと `COLOR()` が入り、続きを打つ）。
2026-09-27 利用者の依頼で、値をドロップダウンから選べるようにする。決定: 範囲は「値が決まっているもの全部」、複数並べられる値はチェックボックスの一覧（SDA の表示属性の選択と同じ考え方）。

## 完了条件 (受け入れ基準)
- [ ] AC1: 値の一覧を原典の詳細ページから生成スクリプトで抜き出す（画面・帳票・物理/論理、日英）。取り方は構文の `A | B`・定義リスト・表・要約。対象外は理由を書く。`--check` を検査に入れる（生成・単体テスト）。
- [ ] AC2: 値の一覧があって括弧が必須のキーワードは、足すときに値を選ばせてから書く（空の括弧を書かない）。単一の値はドロップダウン、一覧に無い値も書ける位置は候補つきの入力欄、複数の値はチェックボックス（単体テスト・GUI e2e）。
- [ ] AC3: 既にあるキーワードのチップを開くと、今の値が選ばれた状態で出て、選び直すとすぐ書き換わる。複数の値は原典の順に並べる。一覧の形に読めないもの（P フィールド等）は選ばせず理由を出す（単体テスト・GUI e2e）。
- [ ] AC4: 選択が書いた形は実機で作成できる（画面・帳票・物理ファイル）。対照として原典に無い値は実機が弾く（実機）。
