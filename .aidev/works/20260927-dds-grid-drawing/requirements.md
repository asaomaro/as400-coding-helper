# 要件: 罫線をマウスで引く・動かす

## 背景 / 課題
罫線（`GRDBOX` / `GRDLIN`）は描画だけで、作るには `GRDRCD` の様式とキーワードを手で書くしかなかった（2026-09-27 利用者の依頼）。
SEU（ACS）には罫線を画面で描く操作が無く揃える先が無いため、操作の形は利用者に 1 件ずつ確認して決めた（`.aidev/backlog/dds.md` の決定）。

## 完了条件 (受け入れ基準)
- [ ] AC1: ツールバーの「罫線を引く」を押し、キャンバスをドラッグした範囲に罫線を引く。縦横とも 2 以上なら `GRDBOX`、1 行なら `GRDLIN … LOWER`、1 桁なら `GRDLIN … RIGHT`（単体テスト・GUI e2e）。
- [ ] AC2: 入れる様式は、一覧で選んだ罫線の様式（`GRDRCD`）、選んでいなければ唯一の罫線の様式。無ければ名前を聞いて `GRDRCD` の様式を作る。入った様式を状況表示で言う（単体テスト・GUI e2e）。
- [ ] AC3: 罫線をクリックで選び、ドラッグで移動、つまみで伸縮、矢印で 1 桁・1 行動かし、Delete で消す。いずれも `*POS` を書き換え、触らない指定（`*CONTROL`・`*DS3`/`*DS4` のもう一方）は残す（単体テスト・GUI e2e）。
- [ ] AC4: 色・線種はツールバーで引く前に選ぶ（既定は「指定しない」で書かない）。選んだ罫線のプロパティで色・線種・形（箱の HRZ/VRT と間隔、線の UPPER/LOWER/LEFT/RIGHT）を後から変えられる（単体テスト・GUI e2e）。
- [ ] AC5: 書いたキーワードは実機の `CRTDSPF` を通る（実機）。
