# 要件: lint core にキーワード使用レベル検査を足す

## 背景 / 課題

DDS のキーワードは**書ける場所が決まっている**（ファイル / レコード / フィールド）。
`DSPSIZ` はファイル、`OVERLAY` はレコード、`COLOR` はフィールド。
**違うレベルに書くと実機はコンパイルを通さない**が、lint は何も言わない。

補完はこのデータを既に使っている（`keywordsForLevel`）。**検査には使っていない。**

## 目的 / ゴール

書けないレベルに書いたキーワードが lint で分かる状態。
**知らないキーワードは咎めない。**

## ユーザーストーリー

- US1: DDS を書く人として、レベルの誤りを保存時に知りたい。
  なぜならコンパイルするまで気付けず、エラーメッセージも桁を指すだけだから。
  （受け入れ: AC1, AC2）
- US2: 同じ人として、**正しいソースに指摘を出さないでほしい**。
  なぜなら偽陽性が出る検査は切られ、切られた検査は無いのと同じだから。
  （受け入れ: AC3, AC4）

## 完了条件 (受け入れ基準)

- [ ] AC1: 書けないレベルのキーワードを指摘する（ファイル / レコード / フィールド）。
- [ ] AC2: **実機がその形を通さない**ことを確かめてある。
- [ ] AC3: 原典がレベルを書いていないキーワードは**咎めない**。
- [ ] AC4: 実機コンパイル確認済みのサンプルで**偽陽性 0 件**。
- [ ] AC5: 既定 ON（AC4 を満たすため）。設定で切れる。
