# 計画: キーワード使用レベル検査

## 作業順序と依存関係

1. 実機でレベルの規則を確かめる
2. 軽い資源を生成する（依存: 1）
3. core の判定（依存: 2）
4. 検証済みサンプルで偽陽性を数える（依存: 3）→ 0 件なら既定 ON
5. 診断とレイアウトへ配線（依存: 4）
6. 規則の登録と設定（依存: 5）
7. 単体テスト（依存: 5）

## リスク / 留意点

- **偽陽性が出たら既定 OFF**（既存の枠に合わせる）。先に数える。
- 束が重くならないように、資源は名前とレベルだけ。

## テスト方針

- 実機: 正しいレベル（対照）＋ 違うレベル 6 通り。
- 単体: 表の引き方（総称の `CFnn` を含む）/ 指摘が出る・出ない /
  **検証済みサンプルで 0 件**。
- 戻して落ちることを 2 通りで確かめる（診断を外す / 「判断しない」を外す）。
