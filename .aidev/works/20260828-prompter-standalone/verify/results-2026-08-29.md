## 未検証の穴（deliver へ引き継ぐ）

- **`npm run test:integration` を手元で回せていない。** `xvfb-run` がこの環境に無く、
  Electron の拡張ホストを起こせない。**CI の `integration` ジョブで確認する。**
  影響範囲は「F4 で例外なくプロンプターが開くこと」——今回パネルの作り方
  （`localResourceRoots` の追加・`onDidDispose` での決着）を変えているので、
  **CI が緑になるまでは確認できていない**と扱う。
- **実機（IBM i）は関係しない。** 桁の書き戻しは `commandText.ts` へ移しただけで
  中身を変えておらず、全 538 定義の往復検証が緑。

- **VSCode 無しで定義から画面が組み上がる**（SBMJOB の 47 欄） — 47 欄
- 見出しがコマンド名になっている
- 開いたら最初の欄にフォーカスがある（キーボードだけで始められる） — CMD
- 修飾名が 1 つの囲みに入り、見出しが付く — ジョブ記述 / ジョブ待ち行列 / 出力待ち行列 / メッセージのロギング
- 囲みの中は末端の入力欄（group そのものには欄が無い）
- F10 で追加パラメーターが現れる — 11 → 47
- ボタンの文言が切り替わる
- もう一度 F10 で畳まれる
- **1 文字ごとに描き直してもフォーカスとカーソルが飛ばない** — 値 "CALL PGM(MYPGM)" / 位置 15
- **構成を作り直しても入力した値が残る**（F10 を挟んでも消えない） — CALL PGM(MYPGM)
- 値がコマンドの欄にだけ F4 の印が出る
- F4 で入れ子のプロンプターが開く — 開いた定義: CALL
- **欄に書いてあった値が入れ子に引き継がれる** — MYPGM
- 入れ子で確定すると、素の 1 行コマンドが欄に戻る（桁揃えも折り返しもしない） — CALL PGM(*LIBL/OTHERPGM)
- 確定できる
- **書き戻される行が桁どおり**（1-13 ラベル欄・14 桁目からコマンド） — "             SBMJOB     CMD(CALL PGM(*LIBL/OTHERPGM))"
- Esc で取り消しになる
- Cancel ボタンでも取り消しになる
- **メッセージ ID を入れると メッセージ・ファイル が必須になる**（group の規則が末端に効く） — なし → LIB,MSGF
- 装置を選ぶ前は保管ファイルの欄が出ていない — どちらも無し
- **装置に *SAVF を入れると保管ファイルの欄が現れる**（PMTCTL が入力に追従する） — SAVF
- 装置を替えると入れ替わる — MEDDFN
- 必須が空のままなら確定しない — outcome="" 赤字=MSGF
- 止めた欄にフォーカスが移る — MSGF
- 埋めれば確定できる — "             SNDPGMMSG  MSGID(CPF9898) MSGF(*LIBL/QCPFMSG)"
- **排他の相関（MSG と MSGID）が帯に出る** — MSG を指定した場合、MSGID、MSGF、MSGDTA は指定できません。(CPD2443)
- 相関に違反している間は確定しない
- 繰り返し group にだけ「追加」が出る
- 1 組目には「削除」を出さない（消すとパラメータ自体が無くなる）
- 追加すると組が増え、入力欄名に連番が付く — SNGVAL,SNGVAL#2,SNGVAL#3
- 2 組目以降にだけ「削除」が出る
- 組を増やしても、他の欄に入れた値が残る — KEEPME
- **途中の組を消すと後ろが繰り上がる**（連番が飛ぶと値と入力欄名の対応が崩れる） — 組=SNGVAL,SNGVAL#2 2組目=THIRD
- 上限のある欄は複数値欄になる（CALL の PARM は 255 件）
- 「追加」で入力欄が増える
- **空の欄は落として配列で確定する** — { "PARM": [ "'A'", "'B'" ], "LIB": "*LIBL", "PGM": "MYPGM" }
- 複数値は空白区切りで書き戻される — "             CALL       PGM(*LIBL/MYPGM) PARM('A' 'B')"
- 「-」で入力欄を減らせる
- 種類ごとに候補一覧が出る
- **欄に候補が紐づく**（定義に objectKind があるだけでは死蔵）
- **CL 変数が maxlength で打ち切られない**（MSGID は 7 文字だが & + 名前 10 まで） — size=7 maxlength=11 値=&MSGIDVAR
- F1 でヘルプが開く
- **Esc で閉じ、フォーカスが元の欄へ戻る**（戻さないとキーボード操作がここで途切れる） — MSGID
- 印をクリックしても開く
- 背景をクリックすると閉じる
- コマンド全体のヘルプも開く
