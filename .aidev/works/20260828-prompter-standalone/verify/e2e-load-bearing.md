# e2e が後退を捕まえることの確認（2026-08-29）

AGENTS.md「落ちないテストは何も守っていない」に従い、**守りたい後退を 1 つずつ戻して
`node dev/prompter-e2e.mjs` が赤になること**を確かめた。6 件すべてで落ちた。

| 戻した後退 | 落ちた検査 |
|---|---|
| `maxlength` から CL 変数の余地を外す（`Math.max(maxLength, 11)` → `maxLength`） | **CL 変数が maxlength で打ち切られない** — `maxlength=7 値=&MSGIDV`（打ち切られた） |
| 見えない欄でも確定を止める（`shown()` の絞りを外す） | **隠れている必須の欄（条件・F10 の両方）は確定を止めない** — `outcome=""` |
| 組を消したときの繰り上げをやめる | **途中の組を消すと後ろが繰り上がる** — `2組目=SECOND`（消したはずの値が残る） |
| 相関の違反を描画モデルに載せない（`constraintErrors: []`） | **排他の相関（MSG と MSGID）が帯に出る** |
| F10 の畳みをやめる（`shown()` が常に真） | F10 で追加パラメーターが現れる — `47 → 47` |
| 入れ子で確定した値を `session.values` に入れない | 入れ子で確定すると、素の 1 行コマンドが欄に戻る — `CALL PGM(MYPGM)`（更新されない） |

## 単体テスト側でも 1 件

| 選択肢に無い値を足さない（`withCurrentValue` を外す） | `**ソースに書かれていた値が選択肢に無ければ足す**`（`prompterWebview.test.ts`） |

## 途中で見つかったこと

最後の 1 件は、**最初は落ちなかった**。調べると当時の実装は
`session.values` に入れたあと入力欄へ直接書いており、その直後の `refresh()` が
DOM から値を集め直すため、**`session.values` への代入が毎回上書きされて死んでいた**。
値の持ち主を `session.values` に一本化し、`rebuild()` で描き直す形に直してから
落ちるようになった（`ui.ts` の `setValue` の注記）。

**「落ちるか」を確かめなければ、死んだ 1 行を正しいものとして残していた。**
