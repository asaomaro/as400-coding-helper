# 調査

## 印の書式（skill §0.2 の生テキスト）

```
      * ==================================================================
      *  検証テスト（VERIFICATION）
      *  オラクル: 設計書 3.2「消費税は円未満を切り捨てる」
      * ==================================================================
```
```
      * ==================================================================
      *  特性化テスト（CHARACTERIZATION）— 検証テストではない
      *  期待値の出所: 2026-08-31 時点の CALCSRV の実際の戻り値
      *  仕様書の裏付け: 無し
      * ==================================================================
```

→ 印は**注記行**にあり、**根拠の行が続く**。この 2 点が機械で見える。

## テスト手続きの見つけ方（skill §1 の生テキスト）

> `export` した手続きのうち**名前が `test` で始まるもの**がテストケースになる。

`setUpSuite` / `tearDownSuite` / `setUp` / `tearDown` は export されるが**テストではない**。
名前で外す。

## 固定長の桁（実物 `tools/example/CALCTST.rpgle` で確認）

| 行 | 桁 |
|---|---|
| 注記 | **7 桁目が `*`**（`      * ===` は 6 空白 ＋ `*`） |
| P 仕様 | **6 桁目が `P`**、名前 7-21 桁、**24 桁目が `B`/`E`**、`EXPORT` はキーワード欄 |

`     PTESTTAX          B                   EXPORT` を数えて一致を確認した
（idx5=`P` / idx6-12=`TESTTAX` / idx23=`B`）。

## 置き場所の判断: lint 規則ではなく道具

| | lint 規則 | `run-rpgunit.mjs` |
|---|---|---|
| 「これはテストか」の判定 | **推測**（NOMAIN ＋ `test*` の当てずっぽう） | **確実**（`RUCRTRPG` に渡す物がテスト） |
| 誤検出 | 普通のサービスプログラムに出る | 無い |
| 届く先 | 編集中の画面 | **レポート（人が読む成果物）** |

lint は拡張機能の利用者全員に効く。RPGUnit を使わない人の普通の RPG に
「オラクルの印が無い」と出るのは**騒音**で、規則そのものが無視される。
道具側は対象がテストだと確実に知っており、かつ**主張が載る場所（レポート）を持つ**。

→ **道具に置く。** 既に独立性の検品が同じ場所にある（検品の置き場として一貫する）。
