# 仕様

## 追加する純粋関数（`tools/run-rpgunit.mjs`）

```js
export function parseOracleMarkers(source)
// → { tests: [{ name, kind, evidence }], problems: [{ name, reason }],
//     verified, characterized, unknown }
```

### 走査

行を上から見る。**注記行**（固定長 7 桁目 `*` / 自由形式 `//`）で状態を持つ。

| 見つけたもの | 動作 |
|---|---|
| 注記に `VERIFICATION` | 効いている印を「検証」に更新。根拠フラグを下ろす |
| 注記に `CHARACTERIZATION` | 効いている印を「特性化」に更新。根拠フラグを下ろす |
| 注記に `オラクル:` / `Oracle:` | 効いている印の根拠フラグを立てる |
| 注記に `期待値の出所:` / `Source:` | 同上 |
| P 仕様の開始（6 桁目 `P`・24 桁目 `B`・`EXPORT`）で名前が `test` 始まり | **そのときの印**を記録 |

**印は「直前のものが効く」**。ファイル頭の印は以降すべてに効き、途中で書き直せば
そこから変わる。1 ファイルに検証と特性化が混在してもよい。

### 欠陥

| 条件 | 理由 |
|---|---|
| 印が無いテスト | `出所不明（VERIFICATION / CHARACTERIZATION の印が無い）` |
| 印はあるが根拠の行が無い | `根拠の行が無い（オラクル: / 期待値の出所:）` |

**単語だけの印は名乗りの偽装**なので通さない。印と根拠は対で意味を持つ。

## 道具の振る舞い

- **既定は警告**。走らせて結果は出す。**レポートに載せる**（緑が独り歩きしないように）。
- `--require-oracle` … 欠陥があれば**走らせずに終了コード 1**。CI 用。
  走らせない理由: 出所不明のまま走ると**緑のレポートが出来てしまう**ため。

## レポート（テンプレート）

追加する差し込み:

| 名前 | 中身 |
|---|---|
| `oracleSummary` | `検証 2 / 特性化 1 / 不明 0` |
| `hasOracleProblems` / `oracleProblems[]` | `name` / `reason` |
| 各 case の `kind` | `検証` / `特性化` / `不明` |

**§0.4 の「特性化は網羅に数えない」**を支えるため、内訳を必ず出す。
