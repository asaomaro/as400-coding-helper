# 仕様: キーワード欄の継続行を実機どおりに読む

## 設計方針

**結合は分類の前に済ませる。** `toLogicalUnits` が行を項目/様式/キーワード行に分けるより先に、
継続でつながった行を 1 つの「機能欄のテキスト」にまとめる。こうすると分類の規則を変えずに済み、
継続元の行は**閉じた引用符を持つ普通の定数行**として分類される（AC1）。

**規則は純関数に閉じる。** `joinContinuations(lines)` を単体で固定できる形にし、
`toLogicalUnits` はその結果を使うだけにする。

**書けないものは拒否する。** 継続行にまたがる項目のキーワード欄は、この版では書き換えない。

## 対象範囲

| ファイル | 変更 |
|---|---|
| `src/core/dds/ddsLogicalUnits.ts` | `joinContinuations` を足し、`toLogicalUnits` が使う |
| `src/core/dds/ddsEdit.ts` | 継続にまたがる項目のキーワード欄の書き換えを拒否 |
| `src/core/dds/{dspfLayout,dspfOutline,dspfRenderModel,prtfLayout}.ts` | **変更しない**（自動的に直る） |

## インターフェース / データ構造

```ts
/** 継続で 1 つにまとまった機能欄。 */
export interface JoinedLine {
  /** 代表行（0 始まりの添字）。位置・長さ・用途はこの行から読む。 */
  readonly index: number;
  /** 結合後の機能欄（45 桁以降）。継続記号は含まない。 */
  readonly keywords: string;
  /** 1 始まりの行番号。**継続に使った行を含む**（削除がまとめて消せるように）。 */
  readonly sourceLines: readonly number[];
}

/**
 * 継続でつながった行をまとめる。注記行・空行はそのまま素通しする
 * （まとめる対象にも、継続の相手にもしない）。
 */
export function joinContinuations(lines: readonly string[]): readonly JoinedLine[];
```

## 振る舞いの詳細

### 継続しているか（機能欄の**最後の非空白**で見る）

| 条件 | 次行の取り方 |
|---|---|
| 最後の非空白が `-` | `-` を捨て、次行の機能欄を**そのまま**（先頭の空白も保つ）連結 |
| 最後の非空白が `+` | `+` を捨て、次行の機能欄の**先頭の空白を捨てて**連結 |
| 上記以外で**引用符が閉じていない** | **空白 1 つ**を挟み、次行の機能欄の先頭の空白を捨てて連結 |
| それ以外 | 継続しない |

- 引用符の状態は `''` をエスケープとして数える（`ddsKeywords.ts` の `skipQuoted` と同じ規則）。
- 連鎖する（結合後にもう一度判定する）。
- **次の行が無ければ**継続しない（そこで終わり）。
- 継続の相手にできるのは**注記行・空行でない行**だけ。注記行が挟まったら継続は切れる。

### 結合の例（すべて実機で確認済み）

| ソース | 結合後 |
|---|---|
| `'ABC-` / `   DEF'` | `'ABC   DEF'` |
| `'ABC+` / `   DEF'` | `'ABCDEF'` |
| `'ABC` / (50 桁目から)`DEF'` | `'ABC DEF'` |
| `'AAA-` / `BBB-` / `CCC'` | `'AAABBBCCC'` |
| `'XYZ'` / `COLOR(-` / `RED)` | `'XYZ' COLOR(RED)` |

最後の例は**2 段**になる: `COLOR(-` と `RED)` が継続で `COLOR(RED)` になり、
それが「キーワードだけの行」として直前の単位へ**空白 1 つ**で足される（従来どおり）。

### `toLogicalUnits` の変更

- 走査の対象を `joinContinuations` の結果にする。
- `keywordAreaOf(line)` の代わりに `joined.keywords` を使う。
- `sourceLines` に継続行を含める。
- **分類の規則は変えない**（名前がある / 定数が読める / 条件だけの行 / キーワードだけの行）。

### 編集の拒否

`setAttributes` で**キーワード欄を書き換える**もの（定数の文字列）は、
対象の単位が**継続行を持つ**なら拒否する。

- 拒否コード: `keyword-continuation`
- 文言: 「キーワード欄が継続行にまたがっています（この版では書き換えません）」
- **位置・長さ・型・用途の変更は拒否しない**（代表行の桁だけを触るので継続に影響しない）。
- 削除は拒否しない（`sourceLines` ごと消える）。

## ドメイン固有の考慮

- **判定は機能欄（45-80）の中だけ**。81 桁目以降は DDS が読まない
  （80 桁を超えた行は実機で `CPD7508` になった）。
- **DBCS**: ソース側は行ごとに SO/SI が入るが、UTF-8 のローカルファイルには現れない。
  結合は文字列の連結でよく、桁の勘定は `printWidth` が持つ（実機と一致することを確認済み）。
- 継続でない「キーワードだけの行」は**空白 1 つ**で連結する（従来どおり）。
  ここを変えると `OVERLAY` を別行に書いた既存のソースが壊れる。

## エラー処理 / 異常系

- 継続記号があるのに次の行が無い → 継続しない（記号は**そのまま残す**。
  捨てると「書いたのに消えた」になる）。
- 引用符が閉じないまま最後の行に達した → そのまま（`readConstant` が読めないだけ）。

## 受け入れ基準との対応

| AC | 満たし方 |
|---|---|
| AC1 | 分類の前に結合するので、継続元の行が普通の定数行になる |
| AC2 | `-` の規則（空白を挟まない） |
| AC3 | `+` の規則（先頭の空白を捨てる） |
| AC4 | 継続記号なしの規則（空白 1 つ） |
| AC5 | 結合後にもう一度判定する（連鎖） |
| AC6 | `keyword-continuation` の拒否。位置・長さは拒否しない |
| AC7 | 継続を含まない行は `joinContinuations` が素通しする。既存テストで固定 |
| AC8 | 実機の Expanded Source と本 PJ の読み取りを突き合わせるテストを置く |
