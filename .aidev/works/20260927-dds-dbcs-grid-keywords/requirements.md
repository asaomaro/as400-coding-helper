# 要件: 画面の罫線キーワード（GRD*）を辞書に入れる

## 背景 / 課題
2026-09-27 の実操作調査（`docs/research/20260927-dds-editor-exploration/findings.md` の D19）で、`GRDRCD` / `GRDATR` / `GRDBOX` / `GRDLIN` / `GRDCLR` を
実機は受け付ける（`v3/CMPLXD.dspf` で `CRTDSPF` 通過）のに、エディタの候補に無く「?」のチップになった。
原典の主の索引（`DSPF-KEYWORDS.html`）に無く、**DBCS を使う表示装置ファイルのキーワードの索引**（`rzakc/dspkwd.htm`）にだけある。
