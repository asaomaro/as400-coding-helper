# 要件: 画面の罫線（GRDBOX / GRDLIN）を描く

## 背景 / 課題
実操作調査（findings.md の D19）で、`GRDBOX` の罫線を持つ様式が実機では受け付けられるのに、エディタは線を描かなかった。
辞書（候補・ヘルプ）は `20260927-dds-dbcs-grid-keywords` で入ったが、描画は残っていた。

## 完了条件 (受け入れ基準)
- [ ] AC1: `GRDBOX` の `*POS (行 桁 深さ 幅)` の 4 辺と、`*TYPE HRZ / VRT / HRZVRT` の罫線を、文字の枠の上に描く（原典: 幅 21・罫線 3 の VRT は縦線 6 本）（単体テスト・GUI e2e）。
- [ ] AC2: `GRDLIN` の `*POS (行 桁 長さ)` と `*TYPE UPPER / LOWER / RIGHT / LEFT [反復] [間隔]` を描く（原典: `RIGHT 4 15` は桁 6・21・36・51 の右境界、`LOWER 3 6` は行 8・14・20 の下）（単体テスト）。
- [ ] AC3: 色と線種は GRDBOX/GRDLIN ＞ 様式の GRDATR ＞ ファイルの GRDATR ＞ 白・実線の順で決める。`*DS3` / `*DS4` の位置は描く画面サイズのものを採る。P フィールドで位置が決まるものは描かない。条件の付いた罫線は標識で消える（単体テスト・GUI e2e）。
