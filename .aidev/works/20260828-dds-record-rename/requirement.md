# 要件: 様式（レコード）の改名と、その参照追随

## 背景 / 課題

デザイナに**様式を改名する手段が無い**。名前の入力欄があるのは項目のプロパティだけで、
様式のプロパティはキーワードしか出さない。

改名するにはテキストエディタへ戻ることになり、そこで手で直すと
**`SFLCTL` などの参照が置き去りになる**。実機はそれを通さない（IBM i 7.3 で確認）:
`SFLCTL` / `ERASE` / `PASSRCD` が存在しない様式を指すとコンパイルできない。

`20260828-dds-rename-references` で項目の改名は追随するようになったが、
様式は「改名の手段が無いので追わない」として起票に回してあった。

## 目的 / ゴール

様式の名前をデザイナから変えられ、**それを指しているキーワードも一緒に変わる**状態。
実機が通さない形（参照が置き去り・名前の重複）が書き出されない。

## ユーザーストーリー

- US1: DSPF を書く人として、様式の名前をデザイナで変えたい。
  なぜなら名前を変えるためだけにテキストエディタへ戻るのは、
  項目の改名ができるようになった今となっては不自然だから。（受け入れ: AC1）
- US2: 同じ人として、`SFLCTL` などの参照も一緒に直ってほしい。
  なぜなら**どのキーワードが様式名を採るかを覚えている必要がある**のは、
  デザイナを使う理由と正反対だから。（受け入れ: AC2, AC3）
- US3: 同じ人として、**実機が通さない名前は断ってほしい**。
  なぜなら同じ名前の様式が 2 つある形はコンパイルするまで気付けないから。
  （受け入れ: AC4, AC5）

## スコープ

### 対象
- 様式のプロパティに名前の入力欄を出す。
- 様式を指す参照の追随（`SFLCTL` / `ERASE` / `PASSRCD` / `HLPRCD` /
  `MNUBARDSP` / `MNUBARCHC`）。
- 実機が通さない名前の拒否（重複・空・11 桁以上）。

### 対象外
- 項目の改名（済。`20260828-dds-rename-references`）。
- 外部を指す参照（`REF` / `REFFLD` / `HLPRCD` のファイル名つき）。**触らない**。
- 継続行にまたがる参照。別項目として起票済み。

## 完了条件 (受け入れ基準)

- [ ] AC1: 様式のプロパティに名前の入力欄が出て、変えるとソースの `R XXXX` が変わる。
- [ ] AC2: 同じソースの `SFLCTL` / `ERASE` / `PASSRCD` / `HLPRCD`（ファイル名なし）/
      `MNUBARDSP` / `MNUBARCHC` の引数も変わる。
- [ ] AC3: **項目を指す参照（`CSRLOC` / `&名前`）は巻き込まない**。表が別。
- [ ] AC4: 既にある様式の名前には変えられない（実機が通さないため）。
- [ ] AC5: 空の名前・11 桁以上の名前は拒否する。
- [ ] AC6: 追随した結果が**実機でコンパイルを通る**。追随しない形は通らない。

## 相互作用の受け入れ基準

- [ ] AC-I1 項目と同じ約束: `Enter` で確定 / `Esc` で戻す / 抜けたら確定。
- [ ] AC-I2 拒否が見える: 断られた理由がプロパティ内に出て、ソースは変わらない。
- [ ] AC-I3 何が一緒に変わるか分かる: 追随するキーワードを断り書きに出す。
