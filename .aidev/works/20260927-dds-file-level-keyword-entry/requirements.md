# 要件: ファイル・レベルのキーワードを 1 つ目から足せるようにする

## 背景 / 課題
- 既存の backlog（`20260908-dds-new-and-records` の retro）と 2026-09-27 の実操作調査（`docs/research/20260927-dds-editor-exploration/findings.md` の D1・D2・D3）で:
  - **D1** 一覧の「ファイル」の節は既に行があるときだけ出るので、行が 1 本も無いファイル（帳票の雛形など）では最初のファイル・レベルのキーワードを足す入口が無い。
  - **D2** 様式の「＋ 追加」が `DSPSIZ` のようなファイル・レベルのキーワードも受け付け、様式の行に書く（実機 CPD7486）。
  - **D3** 引数が要るキーワードを `DSPSIZ()` のように空の括弧で書く（実機 CPD7512 / CPD7498）。検証も指摘しない。
- backlog の例「帳票の雛形に `LPI` / `CPI` を足せない」は、実機で確かめると **LPI / CPI はファイル・レベルに書けない**（CPD7486）。例として誤りだった。

## 目的 / ゴール
行が無くても最初のファイル・レベルのキーワードを足せる。書けないレベル・空の括弧を書かない。

紐づく charter ゴール: DDS の桁支援（ビジュアルエディタ）

## 完了条件 (受け入れ基準)
- [ ] AC1: 行が無くても一覧に「ファイル」の節と足すための行が出て、そこから足すと最初の様式の前に行が入り、その行が選ばれる（単体テスト・GUI e2e）。
- [ ] AC2: 「＋ 追加」でそのレベルに書けないキーワード（検証の `keyword-wrong-level` と同じ表で判定）は書かず、理由を出す（GUI e2e）。ファイル・レベルに書けないものは core も拒否する（単体テスト）。
- [ ] AC3: 括弧が必須のキーワードは `NAME()` で確定せず、生テキストの欄で続きを打たせる。括弧ごと省略できるもの（`PRINT` / `CA03` / `SFLEND`）は名前だけで確定する（単体テスト・GUI e2e）。
- [ ] AC4: 括弧の中が空のキーワードを検証が指摘する（単体テスト）。
- [ ] AC5: 足す経路で作った帳票が実機で作成できる。`DSPSIZ()`・様式の `DSPSIZ`・ファイル・レベルの `LPI` / `CPI` は作成できないことを確かめる。
