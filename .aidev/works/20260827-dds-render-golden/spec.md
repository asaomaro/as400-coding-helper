# 仕様: 描画全体を実機のゴールデンと突き合わせる

## 設計方針

**採取と照合を分ける。** 実機は共用で遅く CI から触れないので、
「実機に出して画面を採る」（人が回す）と「採ったものと比べる」（`npm test`）を切る。

ゴールデンは**画面の生の事実**だけを持つ。モデルの出力を写したものにすると、
モデルを間違えたまま固定してしまう（AGENTS.md「落ちることの確認は、期待値の正しさを
保証しない」）。持つのは ts5250 の画面スナップショットから採った

- 24 × 80 の**文字**
- セルごとの**見え方**（色・反転表示・下線・明滅・非表示）
- 実機が返す**入力欄**（行・桁・長さ・保護）

の 3 つ。**モデルの語彙（`segments` / `occupancy` / `widthCols`）を一切含めない。**

## 対象範囲

- `vscode-extension/test/golden/RENDER1.dspf` — 検査用の様式（新規・原典に沿った固定長）
- `vscode-extension/test/golden/RENDER1.screen.json` — 実機の採取結果（新規）
- `vscode-extension/test/unit/ddsRenderGolden.test.ts` — 突き合わせ（新規）
- `.aidev/works/20260827-dds-render-golden/verify/capture-render-golden.mjs` — 採取（新規）

```jsonc

  "cells": [                       // 空白でないセルだけ（見え方つき）
    { "row": 2, "col": 5, "char": "顧", "color": "green",
      "reverse": false, "underline": false, "blink": false, "nonDisplay": false }

  "fields": [                      // 実機が返す入力欄
    { "row": 6, "col": 12, "length": 20, "protected": false }
  ]

```

## 振る舞いの詳細

### 検査 1: 定数の文字が桁どおりに出ている（AC1）

モデルの `segments` を `column` から並べ、`rows[row-1]` の同じ桁と比べる。
`cols` が 2 の区切りは 2 桁を占め、`shift` の区切り（SO / SI）は**画面では空白**。

**DBCS がここで効く。** `'顧客保守'` は SO + 全角 4 × 2 + SI ＝ 10 桁で、
最初の文字は開始桁の**次**に出る。1 桁ずれるとこの検査が落ちる。

### 検査 2: フィールドが実機の入力欄と一致する（AC2）

用途（38 桁目）が `I` / `B` の項目は**保護されていない入力欄**として、
`O` の項目は**保護された欄**として実機に現れる。行・桁・長さで突き合わせる。

**5250 の入力欄の桁は属性文字の次から**なので、モデルの `column` と一致する
（`occupancy.start` は属性文字の桁で、1 つ手前）。

### 検査 3: 見え方が一致する（AC3）

各項目の**先頭のセル**の色・反転表示・下線・非表示を `item.appearance` と比べる。
非表示（`DSPATR(ND)`）のときは色を比べない——何も出ないので色に意味が無く、
実機は基底の色を返す（`20260827-dds-5250-colors` と同じ扱い）。

### 検査 4: 条件で出ないものは出ない（AC1 の裏）

標識 50 で条件付けた項目は、標識がオフのまま出すと**画面に無い**。
`applyIndicators(model, { "50": "off" })` が同じ項目を落とすことを見る。
**ここが逆向きの担保**——「描いてはいけないものを描いていない」ことは
出ているものを比べるだけでは分からない。

## ドメイン固有の考慮

- **ゴールデンは実機の事実、期待値ではない**（AGENTS.md）。
  採取結果に手を入れて通す、は禁止。落ちたらモデルか様式のどちらかが誤っている。
- **採取の可否と照合の可否を混ぜない**。実機に繋げない環境でも `npm test` は通る。
- 桁は `docs/origin` 由来の `DDS_COLUMNS` に従う。様式は**生成して書き出す**
  （桁を手で数えると必ずずれる。過去に `N50` を 9 桁目に置いて実機で落ちている）。

## エラー処理 / 異常系

- ゴールデンが無い / 壊れている → テストは**落とす**（黙って skip しない）。
  skip にすると「実機と合っている」と誤読される。
- 採取スクリプトは前提（ts5250 の dist・プロファイル・資格情報）が無ければ
  終了コード 2 で止まる。**照合テストはこれに依存しない。**
