# 計画: 行長の数え方を実機の桁に揃える

## 作業順序と依存関係

1. 実機で「切れる場所」と「欄に入る量」を測る（依存: なし）
2. `indexExceedingWidth` を足す（依存: 1）
3. lint / 編集の上限 / 折り返し を `printWidth` に置き換える（依存: 2）
4. 単体テスト（依存: 3）
5. 実機で折った結果を通す（依存: 3）

## リスク / 留意点

- **既存テストの前提が古い**（全角の注記行を「指摘しない」と固定）。
  実機の証拠で直す。消さない。
- `-` で切る位置を桁で決めないと全角が半分に割れる。

## テスト方針

- 単体: 数え方 / 折り返し / 読み直し / 編集の上限 / **半角の回帰**。
- 実機: 折った結果をそのまま `CRTDSPF` に流す（全角 10・16・17・20・34）。
- 戻して落ちることを確かめる。
