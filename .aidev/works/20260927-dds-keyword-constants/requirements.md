# 要件: 文字列の無い定数（DATE / TIME / SYSNAME / USER）を扱う（D4）

## 背景 / 課題
2026-09-27 の実操作調査（`docs/research/20260927-dds-editor-exploration/findings.md` の D4）で、`DATE` / `TIME` / `SYSNAME` / `USER` の項目（名前もリテラルも無い、
キーワードだけの定数）を作れなかった。「定数を置く」は空の文字列を黙って捨て、定数のキーワード欄を `DATE EDTCDE(Y)` にすると
「リテラルで始まる必要があります」で弾いた。確かめると、既存のソースのこれらの行も**項目として読んでおらず**、様式のキーワードの続きと誤読して描かず、
「レコード・レベルに書けない」と誤って指摘していた。

## 完了条件 (受け入れ基準)
- [ ] AC1: 位置とキーワード（DATE 等）だけの行を項目（定数）として読み、実機の桁数で描く。誤った指摘を出さない。一覧の名前はキーワード（単体テスト）。
- [ ] AC2: 桁数は実機で確かめた値（DATE 6 / DATE EDTCDE(Y) 8 / DATE(*YY) 8 / 両方 10 / TIME 8 / SYSNAME 8 / USER 10）（単体テスト・実機のリスト）。
- [ ] AC3: 定数を置くとき種類（文字列 / DATE … / 帳票は PAGNBR）を選べ、選ぶとキーワードで書く。キーワード欄を DATE(*YY) 等に書き換えられる。帳票に SYSNAME は置けない（単体テスト・GUI e2e）。
