# 要件: 帳票の行送りの様式に行番号を書かない／使用を B にしない

## 背景 / 課題
2026-09-27 の実操作調査（`docs/research/20260927-dds-editor-exploration/findings.md` の帳票 P1・P2・P4）で、DDS ビジュアルエディタの帳票（PRTF）について:
- **P1**: 行送り（`SKIPB` / `SPACEA` 等）で行が決まる様式に置いても、必ず行番号（39-41 桁）を書く。実機は CPD7860 × 19 で作成できなかった。
  エディタの検証も、様式に書いた行送りを見ておらず指摘しなかった（項目自身の行送りだけを見ていた）。
- **P2**: 置いたフィールドの使用が `B`（両用）になる。印刷装置ファイルの使用は空白・`O`・`P` だけ（原典 `FIELD-PRTF-prtuse.html`）。プロパティの選択肢も画面用が出る。
- **P4**: 帳票のプロパティに画面用の文言（「属性文字を含む」「CSRLOC / HLPARA」）が出る。

## 目的 / ゴール
エディタで帳票に置いた項目が、そのまま実機でコンパイルできる。帳票のプロパティに帳票に無い概念が出ない。

紐づく charter ゴール: DDS の桁支援（ビジュアルエディタ）

## 完了条件 (受け入れ基準)
- [ ] AC1: 行送りの様式（様式に `SPACEx`/`SKIPx`、または項目が行送り・行番号なし）に置くと、行番号を書かず桁だけを書く。行番号の様式にはこれまでどおり行も書く（単体テスト・GUI e2e）。
- [ ] AC2: 帳票に置くフィールドの使用は書かない（画面は従来どおり `B`）。帳票の使用に `B`・`I`・`H` は書けず、プロパティの選択肢は 空白・`O`・`P`（単体テスト・GUI e2e）。
- [ ] AC3: 様式の行送りと項目の行番号の併用、前の項目の行送りの後の行番号を、検証が `spacing-with-line-number` として指摘する（単体テスト）。
- [ ] AC4: 帳票のプロパティに「属性文字」「CSRLOC」が出ない（GUI e2e）。
- [ ] AC5: エディタの置く経路で作った帳票が実機（IBM i 7.3）でコンパイルできる。併用の対照は CPD7860 / CPD7802、使用 `B` は CPD7410 になる。
