# 要件: 使えない画面サイズ条件名を知らせる

## 背景 / 課題

条件付け欄には画面サイズ条件名（`*DS3` / `*DS4` / ユーザー定義名）が書ける。
しかし**書ける名前には条件がある**。実機はそれを外した形をコンパイルしない（`CPF7311`）。

デザイナ側では**その項目が黙って消える**（1 次画面サイズに合わないので配置されない）ので、
理由を出さないと「なぜ描かれないのか」が分からない。

`20260828-dds-screen-size-condition` で条件名を**書けるように**したので、
デザイナから通らない形を作れる状態でもある。

## 目的 / ゴール

**実機が通さない画面サイズ条件名を、実機に持っていく前に知らせる状態。**

紐づく charter ゴール: DDS の視覚的な確認と編集（第 4 の柱）。

## ユーザーストーリー

- US1: DSPF を書く開発者として、**使えない条件名をその場で知りたい**。
  なぜならデザイナでは項目が消えるだけで理由が出ず、実機で `CPF7311` を見るまで
  分からないから。（受け入れ: AC1, AC2）

## スコープ

### 対象
- 画面サイズ条件名が使える形かの判定と指摘
- lint 規則（既定 ON・error）

### 対象外
- **位置の上書き行を配置に反映する**（`decisions.md` D3。別項目）

## 完了条件 (受け入れ基準)

- [ ] AC1: 使えない条件名を指摘する
- [ ] AC2: 判定が**実機の結果と全件一致**する
- [ ] AC3: lint 規則として CI でも落ちる（既定 ON・error）
- [ ] AC4: **位置の上書き行**（名前もキーワードも無い行）でも指摘できる
- [ ] AC5: 同梱サンプルに指摘が出ない
