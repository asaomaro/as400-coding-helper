# 仕様: 条件標識を編集する（付け外し）

## 設計方針

**桁を打たせない。** 7-16 桁は「7 桁目に A/O、8-10 / 11-13 / 14-16 に `[N]nn`」で、
手で書けば必ずずれる。入力欄は**短い形**（AND は空白 / OR はカンマ）で受け、
桁への書き戻しは core に任せる。

**宛先は行ではなく区間。** 原典より項目は「最後の (または唯一の) 標識と同じ行」に
置くので、OR や 4 つ以上の AND では**条件だけの行が前に増える**。

## 対象範囲

- `src/core/dds/ddsConditionWriteBack.ts`（新規）— 桁への書き戻しと短い形の読み書き
- `src/core/dds/ddsEdit.ts` — `setCondition` と検証
- `src/dds/webview/protocol.ts` — メッセージの型検査
- `src/dds/webview/ui.ts` — プロパティの入力欄

## インターフェース / データ構造

```ts
| { kind: "setCondition"; sourceLine: number; condition: ConditionGroups }

/** OR で結ばれる AND の組。空なら条件なし。 */
type ConditionGroups = readonly (readonly IndicatorTerm[])[];
```

短い形（入力欄）: `N50 01, 60` ＝「(N50 かつ 01) または 60」。
`formatConditionText` / `parseConditionText` が**同じ形**で読み書きする。

## 振る舞いの詳細

### 書き出す行

| 条件 | 行 |
|---|---|
| なし | 代表行 1 本（7-16 桁はブランク） |
| `50` | 代表行 1 本（7 桁目ブランク） |
| `50, 60` | 条件だけの行 1 本（`50`）＋ 代表行（7 桁目 `O`、`60`） |
| AND 4 つ | 条件だけの行 1 本（3 つ）＋ 代表行（7 桁目 `A`、4 つ目） |

### 上限（原典）

> 1 つのフィールドまたはキーワードについて**最大 9 つの条件**を指定することができ、
> 1 つの条件について**最大 9 つの標識**を指定することができます。

超えたら `condition-too-many` で断る。標識が 01-99 でなければ `condition-indicator-invalid`。

### 行がずれたら選択を送り直す

条件の編集は**行数を変えうる**。選択は行番号で持っているので、放っておくと
編集した直後に選択が迷子になる（プロパティごと消える）。
行数の数え方は **`conditionLineCount` の 1 か所**に置き、UI はそれを使って
`sourceLine` を送り直す。**書き出す本数と一致することをテストで固定する。**

## ドメイン固有の考慮

- **注記行が挟まっていたら断る**（`condition-lines-not-contiguous`）。
  区間で置き換えると注記が消える（`setKeywords` の同種の扱いと合わせる）。
- **画面サイズ条件名（`*DS3` 等）は編集しない**。標識とは別の欄の使い方で、
  入力欄は読み取り専用にする。
- キーワードだけの行の条件（`30 DSPATR(RI)` の `30`）は対象外。宛先が項目ではない。

## エラー処理 / 異常系

- 短い形が読めないときは**送らない**。理由をステータスに出し、入力欄を元に戻す。
- 拒否されたらソースは 1 バイトも変わらない（`applyDdsEdits` が空を返す）。

## 受け入れ基準との対応

- AC1/AC2: `writeBackCondition` の桁
- AC3: OR で行が増え、7 桁目に `O`
- AC4: 空の条件で代表行 1 本に戻る
- AC5: `validateCondition` の 3 つの拒否
- AC6: 往復（10 通りの形 × 書いて読み直す）
