- AC1 ✓ 短い形で付けられる（`50` / `N50`）。
- AC2 ✓ 桁は `writeBackCondition` が書く。7 桁目 A/O、8/11/14 が NOT。

### 価値適合
狙いは「見て確かめた条件をその場で書ける」。読む側は前の work で揃っており、
**書けないことだけが残っていた**。桁を打たせない形にしたので、
7-16 桁の 3 桁枠を知らなくても付け外しできる。

### 正確性
- 上限（9 と 9）と `01-99` は**原典の数値をそのまま**使っている（引用つき）。
- 区間はキーワード継続行を巻き込まない（`conditionRunOf` は代表行で止まる）。
- **行がずれると選択が迷子になる**問題を e2e が捕まえ、数え方を core に一本化して直した。

### 規約적合
- 書き戻しは `ddsEditWriteBack` / `ddsPositionWriteBack` と同じ形の独立モジュール。
- `parseEdit` に足した（**足し忘れると画面が「適用中…」で止まる**——`moveColumn` で
  実際に踏んだ）。配線は単体テストで固定した。
- UI の約束（Enter で確定 / Escape で戻す / 抜けたら確定）を他の入力欄にそろえた。

### 保守性
`conditionLineCount` と `writeBackCondition` の一致を 9 通りで機械検査している。
片方だけ直すと落ちる。
