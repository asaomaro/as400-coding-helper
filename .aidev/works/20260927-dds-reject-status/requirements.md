# 要件: 書き換えを弾いたあと状態表示を「適用中…」のままにしない

## 背景 / 課題
2026-09-27 の実操作調査（`docs/research/20260927-dds-editor-exploration/findings.md` の D5）で、DDS ビジュアルエディタのプロパティの書き換えが
拒否されたとき、理由はプロパティ欄に出るのに、ツールバーの状態表示が「適用中…」のまま戻らなかった。
原因は `ui.ts` の `rejected` の分岐のうち、拒否された欄に焦点を戻す経路（`pendingFocus`）だけが状態表示を更新していなかったこと。

## 目的 / ゴール
拒否されたら、状態表示も拒否の理由になる（処理中のまま残らない）。

紐づく charter ゴール: DDS の桁支援（ビジュアルエディタ）

## スコープ
### 対象外
- 同じ backlog 項目の D4（`DATE` / `TIME` / `SYSNAME` / `USER` の項目を作る）。幅の計算・描画・一覧・置く入口の UI まで要る機能で、backlog に分けて残す。
