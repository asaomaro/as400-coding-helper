# 要件: 英大文字だけに縛っている欄を実機に合わせる

## 背景 / 課題
2026-09-27 の実操作調査（`docs/research/20260927-f4-prompter-exploration/findings.md` の P6・P12）で、F4 プロンプターが
- DDS のキーワード欄（45-80 桁）で小文字・日本語の定数を弾き、既存の日本語の定数の行を**何も変えずに確定することもできなかった**。
- ILE RPG の名前（D の NAME、P の PROCNAME）で `loadSubfile` のような大小混在の名前を弾いた。
原因は定義の `characterSet: "upper"`（DDS は生成スクリプトが全欄に付けていた）。

## 目的 / ゴール
実機が受ける値をプロンプターが弾かない。

紐づく charter ゴール: 固定長フォーマットの入力補助（プロンプター）

- [ ] AC2: ILE RPG の D の名前・P のプロシージャー名・F のファイル名に大小混在の名前が書ける（単体テスト）。RPG III は変えない。
