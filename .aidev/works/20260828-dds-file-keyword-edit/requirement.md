# 要件: ファイル・レベルのキーワードを編集できるようにする

## 背景 / 課題

`20260828-dds-file-level-keywords` で `DSPSIZ` / `REF` / `INDARA` / `PRINT` を
**読める**ようにしたが、**編集はできない**。`setKeywords` の宛先は論理単位で、
ファイル・レベルの行は単位にならないため、送っても `line-not-found` で断られる。

プロパティのチップは読み取り専用にしてあった（効かない操作を出さないため）。

## 目的 / ゴール

**ファイルに書かれたキーワードも、様式・項目と同じように直せる状態。**

紐づく charter ゴール: DDS の視覚的な確認と編集（第 4 の柱）。

## ユーザーストーリー

- US1: DSPF を書く開発者として、**`DSPSIZ` や `REF` をデザイナで直したい**。
  なぜなら読めるのに直せないと、結局テキストエディタに戻ることになるから。（受け入れ: AC1）

## 完了条件 (受け入れ基準)

- [ ] AC1: ファイル・レベルの行のキーワードを書き換えられる
- [ ] AC2: **他の行を巻き込まない**（隣のファイル・レベル行が動かない）
- [ ] AC3: 36 桁を超えれば折る（項目のときと同じ経路）
- [ ] AC4: 注記行が挟まる形は断る
- [ ] AC5: 様式・項目のキーワード編集は今までどおり
