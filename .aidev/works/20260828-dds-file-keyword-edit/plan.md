# 計画: ファイル・レベルのキーワードを編集できるようにする

## 作業順序と依存関係
1. `FileKeywordLine` に区間を持たせる（依存: なし）
2. `setKeywords` の宛先を広げる（依存: 1）
3. UI の読み取り専用をやめる（依存: 2）
4. テストと e2e（依存: 3）

## リスク / 留意点
- 区間を間違えると隣のファイル・レベル行を巻き込む。
- `＋` を出すと、使用レベルの候補が無いので空の一覧が出る。

## テスト方針
- 他の行が 1 バイトも変わらないことを見る。
- 折り返しが読み戻せることを見る。
- 宛先の引き当てを外すと落ちることを確かめる。
