# レビュー: ファイル・レベルのキーワードを編集できるようにする

## ラウンド 1（2026-08-28）

### 要件適合
- AC1 ✓ 書き換えられる（e2e で実際に打って確認）。
- AC2 ✓ 隣のファイル・レベル行は 1 バイトも変わらない。
- AC3 ✓ 折り返しは項目と同じ経路。折った結果が読み戻せる。
- AC4 ✓ 注記行が挟まれば断る。
- AC5 ✓ 様式・項目は従来の経路。

### 価値適合
読めるのに直せない状態を消した。前 work で「効かない操作は出さない」として
読み取り専用にしていたので、**出せるようにするのが素直な続き**だった。

### 正確性
編集の種類を増やさず、**宛先の引き当てだけ**を分けた。書き戻しは同じ経路なので、
折り返しの規則が 2 か所に散らない。

### 規約適合
`＋` は出していない——候補は使用レベルで絞っており、ファイル・レベルの一覧が無い。
**空の候補を出すより出さない**（効かない操作を出さない、の続き）。

### 指摘
must 0 / should 0 / nit 0。

**残っているもの**: `＋` の候補（ファイル・レベルのキーワード一覧）。
使用レベルのデータは既に原典から生成しているので、絞り込みを足すだけで出せる。
