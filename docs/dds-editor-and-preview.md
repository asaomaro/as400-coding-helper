# DDS を見る器と編集する器

DDS（`.dspf` / `.mnudds` / `.prtf`）には**器が 2 つ**あり、役割が違う。
どちらもソースを右クリックして開く。

| | **プレビュー** | **DDS ビジュアルエディタ** |
|---|---|---|
| コマンド | `画面プレビュー` / `帳票プレビュー` | `DDS ビジュアルエディタ` |
| 開き方 | テキストエディタの**横**にパネルが出る | テキストエディタと**入れ替わる** |
| ソースとの関係 | ソースが唯一の真実。変更のたびに描き直す | `TextDocument` を共有する |
| カーソル追従 | **する**（ソースで選んだ行が光る） | しない（キャンバス側で選ぶ） |
| 元に戻す | テキスト側の undo | **エディタの undo がそのまま効く** |
| できる編集 | 項目を**動かす**だけ（位置） | 位置・桁数・キーワード・属性・追加・削除 |

## 使い分け

- **ソースを読み書きしながら見た目を確かめたい** → プレビュー。
  横に並ぶので、どの行がどこに出るかを目で追える。
- **見た目の側から作りたい / 直したい** → ビジュアルエディタ。
  掴んで動かす・桁数を変える・キーワードを付け外しする、が一通りできる。

**既定のエディタは奪わない。** `.dspf` をダブルクリックすればこれまでどおり
テキストエディタが開き、ルーラー・SOSI 表示・lint・F4 プロンプターが効く。
ビジュアルエディタは明示的に選んだときだけ開く（`priority` は `option`）。

## ビジュアルエディタでできること

- **配置**: 項目を掴んで動かす、端を引いて桁数を変える、追加・削除する。
- **キーワード**: チップで表示し、`✕` で外す・`＋` で足す・生テキストで引数を直す。
  選ぶと**原典の解説**（和名・使用レベル・構文）が出る。継続行（`-` / `+`）も読める。
- **条件標識**: ソース中の標識を一覧し、3 値（未設定 / オン / オフ）で倒すと描画が変わる。
  未設定は「決まらない」ので**描いたまま**にする。
- **表示の切り替え**:
  - SO / SI を `{ }` で示す（DBCS の桁勘定が合っているか確かめる用）
  - 属性文字（項目の前後 1 桁）を示す
  - 5250 の配色（`COLOR` / `DSPATR` から色・反転表示・下線・明滅・非表示）
  - グリッド / 様式の淡色化 / ズーム
- **帳票のプレビュー**（`.prtf` のみ）: `CPI` / `LPI` を紙の比率に反映し、
  用紙の大きさをインチで出す。値は切り替えられる。

## 帳票（`.prtf`）で気を付けること

行が**行送り**（`SPACEA` / `SPACEB` / `SKIPA` / `SKIPB`）で決まる項目は、
**桁だけ動かせる**。行番号を書き込むと行送りが無効になるため、
エディタは縦のドラッグを起こさない。

## 対応していないもの

- 複数ページの帳票（1 ページ目だけを描く）
- 1 ページの中で `LPI` が変わる帳票（複数あることを注記で知らせる）
- 名前を変えたときの参照（`SFLCTL(NAME)` 等）の追随
- ファイル・レベルのキーワード（`DSPSIZ` / `REF` / `INDARA` / `PRINT`）の表示
