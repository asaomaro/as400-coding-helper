# DDS ビジュアルエディタ・F4 プロンプターの実操作調査（2026-09-27）

本物の VS Code（1.137.0）で、**空のファイルから**複数様式・属性・罫線・サブファイル・ウィンドウを持つ画面（DSPF）と帳票（PRTF）を
DDS ビジュアルエディタで作り、それを動かす RPG と CL を F4 プロンプターで書き、実機（SR-OSAKA・IBM i 7.3）でコンパイルして実行した。
目的はエディタとプロンプターの**不足と不具合を見つけること**。

- 画面・帳票（DDS ビジュアルエディタ）の記録: [`findings.md`](findings.md)（D1〜D19・P1〜P4）
- F4 プロンプターの記録（並行して別のエージェントが調査）: [`../20260927-f4-prompter-exploration/findings.md`](../20260927-f4-prompter-exploration/findings.md)（P1〜P23）
- 実機での実行の画面: `run/*.png`・`run/*.html`、帳票: `run/print-CMPLXP.txt`

## 結果

| 成果物 | 実機 |
|---|---|
| 画面 `CMPLXD`（様式 7: 見出し・サブファイル・サブファイル制御・足元・ウィンドウ・罫線） | コンパイル・実行とも可（エディタだけでは作れず、8 か所をテキストで補修） |
| 帳票 `CMPLXP`（様式 5: 見出し・列見出し・罫線・明細・合計） | コンパイル・実行とも可（行番号を全部外す補修が要った） |
| RPG `CMPLXR`（画面）/ `CMPLXPR`（帳票） | プロンプターの出力のままでは通らず、最小限直して可 |
| CL `CMPLXC` | プロンプターの出力のままで可 |

## 直すべき順（重大度と、利用者が踏む頻度で並べた）

### データを壊す・黙って失う（最優先）

| ID | 何が起きるか | 実機の裏づけ |
|---|---|---|
| DDS D16/D17・P3 | 1 行（80 桁）に収まらない定数を継続行に分けずに書く → リテラルが閉じず**後続の様式を飲み込む**。その定数を消すと**別の様式ごと消える** | CPD7508/CPD7596 |
| DDS D14 | 置き先が**選んだ様式ではなく行の見当**で決まり、別の様式へ黙って入る（ウィンドウ・足元に置けない） | CPD7866 |
| F4 P2 | **4 行目だけ書き戻さない**（`rpgEditGuards.ts:11` の `line === 3` の固定値）。RPG・CL とも | コード直読で確認 |
| F4 P3 | 桁幅を超える値を**左から黙って切る**（`EVAL` の式・`EXTPROC` が化ける） | — |
| F4 P1 | H 仕様書を**書き戻さない・読まない** | — |

### 実機でコンパイルできない形を書く

| ID | 何が起きるか | 実機の裏づけ |
|---|---|---|
| DDS P1（帳票） | 行送り（`SPACEx`/`SKIPx`）の様式にも行番号を書く | CPD7860 × 19 |
| DDS D9 | 使用 `H` に変えても位置を残す | CPD7443 |
| DDS D2/D3 | ファイル・レベルのキーワードを様式に `DSPSIZ()`（空の括弧）で書ける | — |
| DDS P2（帳票） | フィールドの使用を `B` にする | — |
| F4 P4 | 標識・位置・小数・開始位置を左詰めで書く | RNF0263 × 7 |
| F4 P13 | CL の文字列を引用符で囲まない | — |
| F4 P23 | F 仕様の `O` ＋ファイル指定 `F` を通す | RNF2040 |

### 作れない（機能の不足）

| ID | 何が作れないか |
|---|---|
| DDS D10 | 様式キーワードの条件（`31 SFLDSP` 等）＝**サブファイルが組めない** |
| DDS D8 | キーワードの条件（`40 COLOR(RED)`）＝標識で属性を切り替える定石 |
| DDS D1 | 1 つ目のファイル・レベルのキーワード（`DSPSIZ` 等） |
| DDS D4 | `DATE` / `TIME` などの項目 |
| DDS D12/D13 | ウィンドウの枠と中の相対位置・サブファイルの頁ぶんの行の描画 |
| DDS D15 | 項目を別の様式へ移す |
| DDS D19 | 画面の罫線（`GRDRCD` / `GRDBOX` / `GRDLIN`。実機は受け付ける） |
| F4 P6/P12 | DDS の日本語定数・RPG の小文字の名前（英大文字しか受け付けない） |
| F4 P7/P8/P9/P10 | 長さの無い D 行・`ELSE` 等・`N` 型・`K`（キー付き）の F 仕様・C-NEW の条件標識 |

### 検証が見逃す

- DDS D18: 実機で重大度 20 以上になる誤り（上の CPD7443 / CPD7490 / CPD7508）を 1 つも指摘しない。

## 良かった点

- DDS: 様式・項目の追加、型・使用・キーワードの編集、様式名の変更と `SFLCTL(…)` の追随、Ctrl+Z、条件標識の切り替え表示、
  **2 バイト文字の桁勘定と重なりの検証**（行送りを解いて「実機では 2 重印刷になります」と正しく指摘した）。
- F4: 桁の決まった単純な欄の往復、既存行の読み戻し、CL（要素リスト・折り返し・F4 in F4）。

## 再現のしかた

- `driver.mjs`（常駐ドライバー。VS Code を開いたまま HTTP で JS 断片を実行）＋ `lib.js` ＋ `r.sh`。
- `compile.mjs`（実機へ送ってコンパイルし、リストの誤りを抜く）・`run5250.mjs`（5250 セッションで実行して画面を残す）・`runprint.mjs`（帳票を実行してスプールを読む）。
  いずれも `/workspaces/ts5250` の `--env-file` で起動する。スプールは消していない（コンパイル・リストと帳票が `QPRTJOB` に残っている）。
- 実機に作ったもの: `ASAOLIB` の `CMPLXD` `CMPLXP` `CMPLXR` `CMPLXPR` `CMPLXC`、ソース物理ファイル `QDDSJ` `QCLSRCJ`（CCSID 5035）とそのメンバー、`QRPGLESRC` のメンバー。
