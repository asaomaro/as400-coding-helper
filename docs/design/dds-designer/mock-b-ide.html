パターンB：モダン IDE 統合型VSCode カスタムエディタとしての DDS ビジュアルデザイナ（画面モックアップ・非動作）

  • 3ペイン構成。左で構造を把握（様式ツリー＋条件標識）、中央で直接操作、右でプロパティ編集。Figma 等のデザインツールの操作感をそのまま DDS に持ち込む。
  • VSCode に溶け込む。アクティビティバー／タブバー／問題パネル／ステータスバーを再利用し、「テキストで開く」で常に固定長ソースへ戻れる（生成ではなく双方向編集）。
  • DBCS の桁勘定が主役。全角は 2 桁、SO/SI は { } で各 1 桁を占有。{社員マスタ保守} は 1+7×2+1 = 16 桁。桁揃えは ch ではなく --cell-w(px) を基準に組み、全角セルは calc(var(--cell-w)*2) で明示。
  • アクティブ様式は 1 つ。他様式は薄く重ね表示（掴めない）ため、重なりの当たりを見ながら編集できる。条件標識トグルで実行時の見え方を切り替えられる。
  • 診断はキャンバスと連動。桁溢れ・重なりを画面上のマーク／行番号の ⚠ と下部の「問題」一覧の両方に出し、クリックで該当箇所へジャンプする想定。
