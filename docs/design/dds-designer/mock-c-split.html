このパターンの特徴とトレードオフ

  • 常時二面。GUI が扱えない指定（条件標識・DSPATR・ERRMSG など）は、下のソースで直接手を入れられる。GUI と手書きの往復に段差がない。
  • 選択の連動。色・行番号バッジ・ガイド線の3点で対応関係を示す。ソース行をクリックすればキャンバス側が選択される（逆も同じ）。
  • 桁勘定が正。全角＝2桁、SO/SI＝各1桁。{社員マスタ保守} は 1+7×2+1＝16 桁（2-17 桁）を占有し、これはキャンバスにもソースの桁数えにも同じように効く。
  • 差分の最小化。編集した行だけを書き換え、未編集行はバイト単位で保全。M/A バッジと左端の色帯がその範囲を可視化する。
  • 代償。縦を二分するため 24×80 の全景とソースを同時に見ると窮屈になる。スプリッタ／折りたたみ／ソースを右側面に回す配置の切替を前提にしたい。
